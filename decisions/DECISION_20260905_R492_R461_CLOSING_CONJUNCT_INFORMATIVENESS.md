## 二、判準（分類規則，量測前寫死）

對預測 `P` 的每個合取項 `X`，在**可達狀態空間**上問：

- **`FORCED_BY_OTHERS`**：**不存在**任何狀態使得（`P` 的其他合取項全為真）∧（`X` 為假）。
  ⇒ `X` 在這個合取式裡**不帶資訊**；收官**不准**把它當成獨立佐證，要寫「由其餘項單獨承重」。
- **`EVALUABLE`**：存在這種狀態 ⇒ 記一個 witness `(b, c, n)`。
- **`UNSCANNED`**：「其他合取項全為真」的狀態數 **= 0**（連問都問不了）。**不是綠燈。**

**`FORCED_BY_OTHERS` ≠ 有缺陷**（r718 規則）：它只代表這一項不獨立。要警告的是
「收官把它當成第三個獨立證據」。

## 三、可達狀態空間（不是隨機抽樣——memory 鐵律：「隨機抽樣抽不到」≠「恆等式」）

**窮舉** `b, c ∈ ℤ≥0`，`b + c ≤ n`，`n = 189`（＝ R461 §四釘死的 `--n`）。
每個狀態的 `Δ`、`p`、`verdict` 一律**呼叫 `paired_ci.py` 自己的 `diff_ci()` 與 `verdict()`**
（`import`，不是重寫一份；memory 鐵律：不准自己改寫一份運算式）。

`return` 字串字面，比對本判準寫的 `"ON_WINS"`——**對不上就 `CENSUS_BROKEN`**。

主判定用 `n = 189`。`n ∈ {60, 100, 189}` 的掃描列為**補充**，不是仲裁者。
`MIN_PAIRED = 60` 的 BROKEN 擋門在 `n = 189` 上不觸發，照實記。

## 四、雙向校準（缺一不可；只有正對照＝「什麼都判 FORCED」也會全綠）

- **正對照 C-POS**：合成合取項 `p <= 1.0` 掛進 P-R461-1 ⇒ **必須** `FORCED_BY_OTHERS`。
- **負對照 C-NEG**：合成合取項 `Δ > 12.5pp` 掛進 P-R461-1 ⇒ **必須** `EVALUABLE` 且有 witness。

任一方向不成立 ⇒ `CENSUS_BROKEN`，**本輪不對真合取項下任何判決**。
