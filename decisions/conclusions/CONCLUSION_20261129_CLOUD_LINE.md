## 3. 合起來能說什麼、不能說什麼

可以說：
1. 「在這兩個 worker、這兩個題庫、3×600 對 1800 秒的設計下，**沒有量到** C 與 B、R 的差別。」附區間；Haiku 批無法區分、Devin 批資料量小。
2. 「重開比單次好或差，**取決於預算形狀與模型速度**」：Haiku（快）重開臂較高；Devin（慢、常需 >600 秒）單次臂較高。兩者都不是控制器的效果。
3. 「控制器照規則表在執行」：決策鏈雲端兩批 149 條（Haiku 117、Devin r1–r2 32）驗過；本機複核另對 257 個決策事件重推 0 不符。鏈只證明鏈內一致（見第 5 節）。

不可以說：
- ❌「一樣好」「等價」：沒有事前定的等價界限；Devin 區間約 ±14 pp。❌「控制器有效」。❌「控制器無效」。兩個方向都沒有證據。
- ❌ 外推到弱模型：Haiku 在天花板、Devin flash 級在這個池約 69%（邊緣），**沒有雲端的弱模型資料**；本機 9B／E4B／12B 另線，不可互相借用。
- ❌ 把 Haiku 批的「R／B／C 比 A 高」或 Devin 批的「A 比重做臂高」講成控制器或重開本身的效果。
- ❌ 把 post-hoc 子集、r3 敏感度、本文補算區間當成預註冊結論。
- ❌ 「Vacant 讓 agent 做得更好」不帶條件；❌ 把機制模擬講成證明。

1. **Haiku 額度上限**造成 51 格作廢（第 2.2 節）；之後不再開 Haiku 批次。
2. **Devin 免費週額度用盡**，r3 只完成 28／64 格，降為 2 重複；另有 61 格被帳號限流作廢。
3. **容器重啟**中斷 Devin 批次（r3 四格半成品原地保留）。
4. **網路隔離不是作業系統層**：Devin 的網頁工具靠 CLI 的 deny 規則（行程內）擋下 421 次，規則名若隨 CLI 改版失效會靜默破功，應每批前重跑負控制；Haiku 的檔案工具也是 CLI 規則。自查只證明「紀錄裡沒有成功連外」，不證明沒有能力。
5. **B41(5) 方向寫錯**，已更正（第 4 節）。
6. **值雜湊可被窮舉還原**：複核指出「值只放雜湊」擋不住窮舉，補檔應用加鹽雜湊（後續名單核對改用 HMAC）。

## 6. 給擁有者的話（白話）

雲端這條線做了兩個四臂批次：Haiku 和 Devin 免費模型，各自在 Codeforces 難題上比較「做一次」「盲目重開」「重開附失敗回饋」「控制器」。結果是：控制器和另外兩種重開**沒有量到差別**。Haiku 太強，四臂幾乎都成功，沒有東西可以分；Devin 做不完的題多，但我們只有兩個重複、幾對不一致的結果，所以連十幾個百分點的差都排除不了。因此不能說控制器有效，也不能說它沒用，更不能說「一樣好」。有趣的是，重開臂勝過單次還是輸給單次，要看每次給多少時間：快的 Haiku 是重開贏，慢的 Devin 是單次贏，這是預算形狀的效果，不是控制器的。展覽上可以講「每一步決定都有簽章紀錄、事後可重推為什麼在這裡重開」，口徑固定為「可究責性／讓依賴有根據」；不能講「agent 改不了紀錄」，紀錄只證明鏈內一致；也不能把這些數字說成控制器變聰明了。現場若放控制器對照，要標明是機制模擬，不是這批真模型的證明。
