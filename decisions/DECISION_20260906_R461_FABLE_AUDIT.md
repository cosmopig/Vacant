## 二、讀法

1. **形狀與前五個 run 一致**：早停顯著贏單抽（p=0.0167）、與 OFF5 在準確率上分不開（p=0.66）、
   用 1.55 通拿到 OFF5 花 5 通的結果。「執行取代意見；便宜是確定的、更準是未解析的」不變。
2. **lcb3 比 lcb2 容易得多**：OFF 失敗率 27.5%（lcb2 是 49.2%），已回到 MBPP+ 的量級（31.8%）。
   迴圈建 v3 時加了什麼視窗、為什麼難度掉回來，要看 R461 的建庫紀錄；**本 run 不能當「難題複製」讀**，
   它更像 MBPP+ 難度的第二個題庫複製。難題上早停 +19pp（R440Z）的那條，複製仍只有 lcb2 一次。
3. **無損性累計**：MBPP+ 三個 run（0/1630）、lcb v1 重放（0/455）、lcb2 真跑（0/120）、lcb3 真跑（0/189）
   ——六個資料集零違反。R440P 的拒交規則前提到此已在三個題庫的真跑成立。
