# DECISION 2026-08-28 round219 — 澄清 round212 §7 漂移推翻條件的判讀

## 發現了什麼

round212 的 `DECISION_20260828_R212_BUDGET_DECOMPOSITION_PREREG.md` §7（推翻條件，
line 206）寫：「新 OFF 與舊 OFF 的正確率差距 > 本對比的效應量（+2.49pp）⇒
對比降級成『量不到』」。

round216–218 三輪的 GAIN_STATE.md monitoring checkpoint 都量到新 OFF（本次
`g_onr_r212_20260828` run 自己的 OFF 臂）比舊 OFF 高約 +2.7~+4.0pp（依用
79.28% 還是 78.49% 當基準而異），**數字上已經大於 +2.49pp 這個純量閾值**，
但三輪的措辭都寫「接近觸發線」「尚未觸發」——這是文字與自己列出的數字互相矛盾
（3-4pp 本來就大於 2.49pp，不是「接近」）。

## 這是不是真的漂移

不是，或至少現在的 n 量不出來。用二項分布 SE 重算（round219，n=67，
`g_onr_r212_20260828` 的 OFF 臂 `meets_demand`=55/67=82.09%）：

```
SE = sqrt(p(1-p)/n) ≈ 4.68pp
diff vs 79.28%（round212 對比A用的舊OFF）= +2.81pp ≈ 0.60 SE
diff vs 78.49%（R146-S 終點區間中點）   = +3.60pp ≈ 0.77 SE
```

兩種基準下差距都遠小於 1 個標準誤，跟純粹抽樣噪音沒有統計上可分辨的差別。
round212 §7 寫的「> 效應量（2.49pp）」是一個**純點值比較**，沒有寫任何最小 n
或信賴區間條件——在 n=28~67 這種小樣本下，任何兩個獨立二項比例的點估計差
超過 2.49pp 都毫不意外（本例只需 0.6 SE 就夠了）。**照字面套用這條規則會在
每一輪都「觸發」，因為規則本身沒有對噪音設防**。這是 round212 §7 起草時的
遺漏，不是這次量到了真的漂移。

## 決定

**不觸發 round212 §7 的降級。** 補一條運作規則（澄清既有規則，不是新增實驗
條件、不影響任何一臂的抽樣或計分邏輯）：

- 這條漂移檢查要在 **OFF 臂跑完 371/371**（或至少 n≥150，使 SE 降到
  ~3.3pp 以下、與 2.49pp 閾值同量級）時才具備下裁決的統計解析力；n<150 時
  只記錄點估計與其 SE，**不下觸發／不觸發的結論**。
- 這與 round212 本身寫的「終點規則：兩臂都要處理完 371/371 才裁決，中途禁止
  裁決」精神一致——漂移檢查雖然技術上是「已知弱點」的診斷不是 Gate R2 本身，
  但既然它會決定 Gate R2 結論要不要降級，就不該用比 Gate R2 更寬鬆的證據
  門檻來裁決。
- 之後每輪 monitoring checkpoint 報這個數字時，**必須同時報 SE 與差距的
  SE 倍數**，不要只報點估計差距，避免重演「數字已經超過閾值但文字說沒有」
  這種矛盾。

## 為什麼現在澄清、不是等 371 再一次講清楚

round216-218 三輪都各自量出「已經接近/超過」卻各自判定「先不動」，等於用了
一個沒寫清楚判準的規則三次、每次都靠當輪的人工判斷擋下——這正是
「先寫死判準」原則要避免的事後補規則。現在把判準寫死（n≥150 才能裁決），
下一輪起可以機械式套用，不用每輪重新судить要不要觸發。

## 推翻條件

- 若 n≥150 時 |diff| 仍 >2.49pp 且 z≥1.96（近似對應 p<0.05），才真的觸發
  round212 §7 的降級，屆時另立 DECISION 記錄降級後果。
- 若這條 n≥150 門檻本身造成 OFF 臂都快跑完了才能裁決、實質上跟直接等
  371/371 沒有差別，下一輪可以判斷乾脆刪掉這條中途檢查、只在終點做一次。
