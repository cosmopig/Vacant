# 裁決：分身每一步說一句話（2026-10-01）

人類原話：「沒有呈現出數位分身想要什麼、他在想什麼、過程如何被發展」。

## 問題
真 pi（0.85.1）＋gemma 實測：中間回合只有 thinking＋toolCall，text 只出現在收尾、還常帶檔名；
thinking 是英文且會照抄特質，不能直接上電視。結果 `twin_say` 幾乎只剩收尾一句。

## 改了什麼
`ops/exhibit/twin/twinagent.py` 的 `SYSTEM_PROMPT`「規則」段**加一句要求**：
「每一次動手（讀、寫、列出）之前，先用一句繁體中文說你現在在想什麼、接下來要做什麼；這句話裡不要寫檔名。」

- 只是要求它說出來；**不給例句、不給任務方向**（人類：不准罐頭句、不帶風向）。
  `test_system_prompt_gives_no_examples` 仍過。
- 三段固定文字仍逐字相同、import 時過 KS-1（`assert_ks1_clean`，未繞過）。
- 句子仍是 agent 生成的原樣字；LEAK（連續 ≥8 字抄觀眾原文）與檔名防呆照舊。

## 實測（VM 真 pi 0.85.1，gemma-4-12b-it-qat，合成特質，三跑，暫存目錄、跑完已清）
| 跑 | assistant text 區塊 | 工具呼叫 | 實際發出 `twin_say` | LEAK 擋 | 檔名擋 |
|---|---|---|---|---|---|
| 1 | 3 | 3 | 3 | 0 | 0 |
| 2 | 4 | 4 | 3 | 0 | 0 |
| 3 | 3 | 3 | 3 | 0 | 0 |

每跑 ≥3 句、全為繁體中文。樣本：`tests/fixtures/pi_json/real_pi_0.85.1_say_prompt_{1,2,3}.jsonl`。
邊界：樣本只有 3 跑、同一份合成特質；沒有量到 LEAK／檔名防呆被擋的比例（0/9），
防呆的觸發率要更多跑才知道；第 2 跑有 1 個 text 區塊清過後為空而沒發。
