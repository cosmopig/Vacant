## 一、要修的三個缺陷（每一條都先證明，再改）

### D1　`max` 擋門沒有水準，`R` 悄悄決定了顯著水準

R489 的擋門是「20 次重複裡 `|log placebo|` 的**最大值** >= `|log real|` ⇒ `PERIOD_CONFOUNDED`」，
理由寫的是「保守方向：只會讓正向宣稱更難成立，不可能對我有利」。保守是對的，**但它沒有水準**：

- `max` 對 `R` **單調不減**（多抽一次只能讓最大值變大或不變）。
- 「所有 R 次都小於 real」⟺ 置換 p 值 `p = (1 + #{|log placebo| >= |log real|}) / (R+1)` 取到最小值 `1/(R+1)`。
- ⇒ **這個擋門恰好等價於水準 `1/(R+1)` 的置換檢定**。R489 取 `R=20` 是為了算得快，
  於是把水準訂成 `0.048`——**沒有人決定過這件事**。R 一調大，水準就往 0 跑，
  `CONCURRENCY_TAXES` 在 `R -> 無限` 時結構上不可達（＝強制紅燈的一種）。

⇒ **改法：擋門換成明寫水準的置換 p 值，`ALPHA = 0.05`。**
⚠ 這個改動的方向對我有利（更容易宣稱有稅），所以理由必須不是「這樣才通得過」：
本輪因為 D2 必須把 `R` 從 20 提到 400（見下），**若沿用 `max`，水準會從 0.048 悄悄變成 0.0025**。
換成明寫的 `ALPHA=0.05` 是**維持 R489 實際採用的水準不變**，不是放寬它。
`R=20` 下兩者幾乎同義（`1/21 = 0.048`），差異只在我提高 R 之後才出現。

### D2　錨點 A 量錯了東西（round760 已發現一半，本輪合成復現補完另一半）

R489 錨點 A：`median|log ratio| <= 0.08`，門檻是從**真實估計的 bootstrap CI 寬度**反推的。
round760 已記：bootstrap（hi/lo 由資料決定）與置換（hi/lo 隨機指派）沒有理由共用變異數。
本輪的合成復現 `2dcca08` 再往下推兩層：

- **D2a　舊規則不是「中心」的函數。** 兩個構造出來的分佈：中心**恰好 0.000**、較寬的那個
  被判 BROKEN（`median|log| = 0.1075 > 0.08`）；中心**恰好 +0.070**、較窄的那個被判 FINE。
  ⇒ 一個完美合格的安慰劑被拒絕，一個真的製造了 7% 關聯的安慰劑被接受。**它量的是寬度不是位置。**
- **D2b　最直覺的修法（`|mean|/se <= K` 顯著性檢定）是強制紅燈。**
  這個比值型估計量的置換分佈帶著 `O(1/n)` 的 Jensen 偏移（合成母體實測
  `-0.0258 / -0.0090 / -0.0014`，對應 `n = 300 / 1000 / 4000`）。`se` 隨 `1/sqrt(R)` 縮，偏移不縮
  ⇒ 在**因果效應構造上為零**的母體上，`|z|` 投影 `0.85 (R=25) -> 3.40 (R=400) -> 10.74 (R=4000)`。
  R 夠大就必然判 BROKEN。
- **D2c　兩邊都活得下來的是「對實用邊際做等效檢定」。**

⇒ **改法：錨點 A v2 ＝「全域置換分佈的中心，其 `mean ± K*se` 必須整段落在 repo 既有的實用邊際帶內」**，
`K = 3`，帶 = `[log 0.90, log 1.15] = [-0.10536, +0.13976]`（R487 起就在用的 `EQUIV_LO/EQUIV_HI`）。
**新增可調參數：0 個**（`K=3` 沿用常態三倍標準誤的慣例，帶沿用既有常數）。
`R_GLOBAL = 400`（合成復現顯示 `R=25` 時等效檢定會**拒絕認證**＝正確行為，`R>=200` 才認證得出來）。

### D3　階梯的低階不是擋門，是正對照——round760 的「沒有平台」問錯了母體

R489 自己的判準文就把 `B=60` 寫成 **「錨點 B（正對照｜安慰劑必須保留局部結構）」**：
`B` 越小捐贈者在時間上越近 ⇒ 安慰劑曝光**越接近真實曝光** ⇒ 安慰劑比值必然趨近真實比值。
round760 交棒第 4 點把擋門套到 `B=60/300` 上、得出「階梯沒有平台、翻面點在 300↔900」，
**那是把正對照當成擋門在讀**：一個「必須重現真實關聯」的階，結構上不可能通過
「必須小於真實關聯」的擋門。同一階不能同時是正對照又是擋門。

⇒ **改法：用階自己的 `agreement` 決定它的角色，門檻沿用既有的 `ANCHOR_B_MIN_AGREEMENT = 0.50`
（新增可調參數 0 個）：**

- `median agreement >= 0.50` ⇒ 這一階是**正對照**：它必須**重現**（`p > ALPHA`）。
  **反方向也有牙齒**：正對照階若 `p <= ALPHA`（拿到幾乎相同的曝光卻重現不出真實關聯）
  ⇒ 安慰劑機制本身壞了 ⇒ `PLACEBO_LADDER_BROKEN`。
- `median agreement < 0.50` ⇒ 這一階是**擋門**。「有沒有平台」只能在擋門階之間問。

**主判區塊維持 R489 訂的 `B = 1800`，本輪不重挑**（重挑＝看過數字挑贏家）。
若 `B=1800` 這一階的 `agreement >= 0.50`，它就不是擋門 ⇒ 判 `PRIMARY_IS_POSITIVE_CONTROL`，
**本輪照實記「R489 挑的主判區塊不能當擋門」，不准當場改挑別的 B。**

## 二、判決順序（單一決策點，所有輸入由呼叫端獨立設定）

```
 1. real 兩臂任一 < MIN_PER_ARM(50)             -> EXPOSURE_DEGENERATE
 2. real coverage < MIN_COVERAGE(0.50)          -> UNSCANNED
 3. real ratio / CI 缺                           -> UNRESOLVED
 4. CI 含 1.0：整段在 [0.90,1.15] -> NO_TAX；否則 -> UNRESOLVED     （沿用 R489 的順序修復）
 5. 任一階的 p 或 agreement 量不到               -> LADDER_UNSCANNED
 6. 錨點 A v2 或 錨點 B 不成立                   -> PLACEBO_LADDER_BROKEN
 7. 任一正對照階 p <= ALPHA（重現不出來）        -> PLACEBO_LADDER_BROKEN
 8. 主判階 coverage 不足／p 缺                   -> PLACEBO_UNSCANNED
 9. 主判階兩臂任一 < MIN_PER_ARM                 -> PLACEBO_DEGENERATE
10. 主判階 agreement >= 0.50（它是正對照）       -> PRIMARY_IS_POSITIVE_CONTROL
11. 主判階 p > ALPHA                             -> PERIOD_CONFOUNDED
12. real ci_lo > 1.0：
      任一**擋門階** p > ALPHA                   -> SCALE_DEPENDENT_TAX
      hi <= 1.15                                 -> TAXES_BELOW_MARGIN
      否則                                       -> CONCURRENCY_TAXES
13. real ci_hi < 1.0                             -> SPEEDUP_ANOMALY
14. 其餘                                         -> UNRESOLVED
```

`p = (1 + #{ |log ratio_placebo| >= |log ratio_real| }) / (R + 1)`，`ALPHA = 0.05`，`R = 400` 每一階。
**14 個判決每一個都要有一組輸入到得了**，寫成 selftest 斷言（強制綠燈／強制 UNRESOLVED 的例行檢查）。

**舊規則一併落盤**：`abs_log_max` 在 `R=20`（R489 的設定）與 `R=400` 兩個值、
舊錨點 A 的 `median|log|`、以及**用舊規則跑出來的判決**，全部寫進輸出，但**不具約束力**。

## 六、誠實邊界（事前寫，不是事後補）

- **錨點 A v2 容許安慰劑製造最多 `log 1.15 = 0.1398` 的關聯**，＝R488 真實點估計 `log 1.8652 = 0.6234`
  的 **22%**。它認證的是「安慰劑在實用邊際內是虛無的」，**不是「安慰劑恰好是虛無的」**。
- `NO_TAX` 仍然**不過安慰劑**（沿用 R489 的順序修復）⇒ 無法排除「真有稅、被反號的期間混淆遮成虛無」。
- 錨點 A 的改動**方向對我有利**；唯一的理由是 `2dcca08` 的合成復現與 D1/D2 的語意，
  **不是「這樣才判得出來」**。舊門檻 `0.08`、舊輸出、舊判決全部保留並照算。
- 本輪只重算，**沒有任何新資料**：`p` 的解析度上限是 `1/(R+1) = 0.0025`。
- 「安慰劑重現不出真實關聯」與「真的沒有期間混淆」在 `p` 上長得一樣小；
  正對照階（第 7 步）就是為了把前者從後者分出來，**但它只在有正對照階存在時才生效**。
