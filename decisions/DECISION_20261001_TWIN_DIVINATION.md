# 裁決：分身指令改成「占卜」（2026-10-01）

人類原話：「輸出的東西我覺得很莫名其妙，就是輸入的提示詞其實應該要改更深入，
我想要有占卜的感覺，要讓人會有『啊這真的是我可能會想的事情』如果我在那個世界裡的話」。

人類實測的那一跑：分身決定「寫自我定義宣言」——一件**在談論自己這個存在**的事，
不是世界裡的事，也看不出跟這位觀眾的關係。

## 改了什麼（只改 `ops/exhibit/twin/twinagent.py` 的 `SYSTEM_PROMPT` 步驟段）

| | 舊 | 新 |
|---|---|---|
| 想什麼 | 「決定一件你想在這個世界完成的實務小事」 | 先讀 TRAITS.md，再**讀進字面以外的東西**：沒說出口的在意、渴望或拉扯；他心裡可能一直掛著哪一件事 |
| 選什麼 | 想完成的小事 | 「**如果他此刻就在這個世界裡，真的會想去做**」的實務小事；要做的是世界裡的事，不是在談論你自己這個存在的事 |
| PLAN.md | 第一行決定＋兩三句為什麼選它 | 三段：第一行決定；一段「為什麼是你」（對觀眾本人說話、第二人稱、以「因為你……」開頭、具體點出從哪些線索讀到）；最後一段打算交出什麼 |
| 成品檔名 | 自己取、副檔名 .md／.txt | 同，加「中文或有意義的名字都可以」 |
| 逐字抄錄 | 「不要在檔案裡逐字抄錄 TRAITS.md 的內容」 | 加「要寫的是你從它讀出來的東西」 |

不動：三段固定文字逐字相同、argv 無觀眾原文、import 時過 KS-1、「每一次動手之前先說一句」
（DECISION_20261001_TWIN_SAY）、`allow_no_suite`（`accepted=null`，**不經任何審查閘門**）。

## 紅線（都是負向約束，不給正向例子）

* 不給例句、不給任務方向、不准罐頭句。
* prompt 裡**不得出現**後設任務引導詞（身份／身分／自我定義／自我介紹／宣言／分身本身／自己是分身）
  與「占卜／算命／運勢」（後者會把分身帶去寫算命）。禁止後設任務的說法只用「不是在談論你自己
  這個存在的事」一句，不點名任何具體任務種類。測試：
  `tests/test_twin_agent_run.py::test_system_prompt_divination_structure_and_no_meta_guidance`（含負控制）。

## 誠實邊界

* 6 筆、一個模型、每張卡跑一次：只夠人讀，不是統計。「有占卜感」是人讀出來的，不是量出來的。
* 「為什麼是你」那段仍常常是特質的**改寫**（有時連片語都原樣出現）；prompt 禁的是逐字抄錄檔案內容，
  不是這段的字面重疊。這一點沒有解決，要不要處理屬於之後的審查設計。
