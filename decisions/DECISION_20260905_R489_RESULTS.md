## 一、機制：置換安慰劑確實修好了 R488 的塌陷（P-1a 兌現）

R488 的時間平移安慰劑，低曝光臂從 728 列塌到 2–10 列 ⇒ `ratio=None` ⇒ 掃不到。
本輪的區塊內置換（主判 `B=1800`，H=start）：

```
                     coverage    n_hi   n_lo
real (own start)      1.00000     371    357
placebo B=1800        0.99863     370    357     <- R488 是 2-10
```

**塌陷消失，而且不是勉強過關**——安慰劑的兩臂跟真實估計幾乎逐列一致。
這是預註冊寫下的恆等式的結果：區塊內置換保留起始時點的多重集合，
邊際曝光分佈在構造上不變（selftest 有窮舉斷言）。

## 二、階梯（全部落盤，預註冊寫明其餘 B 為敏感度）

H=start，`|log real ratio| = 0.62338`：

```

      60 s        0.6782        0.6782       1.9704      0.9966     278   303

```

- **錨點 B（正對照）通過**：`B=60` 的 agreement 中位數 **0.9966 >= 0.50**。
  區塊很窄時安慰劑幾乎重現真實曝光 ⇒ 置換確實保住了局部結構。

  預註冊寫死「**不准改門檻重跑**」，本輪照辦：**門檻沒動、沒重跑、判決就是沒有答案。**

H=end 只是敏感度（P-1 已解出 `TS_IS_START`）：它的錨點 A **通過**（0.0616）而錨點 B **失敗**（0.4611），
判決 `UNRESOLVED`，`sensitivity_agrees=False`。兩支的錨點恰好失敗在相反的那一邊。

## 三、事後診斷（**post-hoc，不計入預測帳**）：那道錨點是強制紅燈

`ops/gain/r489_anchor_a_diagnostic.py`，全域置換跑 200 次重複：

```
mean log = +0.01046   sd = 0.10160   se(mean) = 0.00718   mean/se = +1.46   median|log| = 0.09991
P(錨點 A 通過 | 安慰劑就是它現在這麼有效) = 0.0075   (149/20000 次「20 抽的中位數」重抽樣)
```

兩件事分得很開：

1. **不是偏誤**：平均 log 只有 +0.0105，`mean/se = 1.46` ⇒ 全域置換確實是虛無的，
   安慰劑**沒有**系統性偏掉。
2. **是我把門檻訂在雜訊尺度以下**：置換統計量的 sd 是 **0.1016**，
   而我用來推門檻的是**真實估計的 bootstrap CI 寬度**反推的 0.0569（差 1.79 倍）。
   一個完全有效的安慰劑，它的 `median|log|` 期望值就是 **0.0999** ——
   **比我訂的門檻 0.08 還大**。⇒ 這道門在設計當下就幾乎不可能通過。

⚠ **通則（本輪最該記住的一條）**：
「就算訊號完美，這條判準有沒有可能仍吐不出判決」這個問題，
**不只要問判決分支，也要問校準門與擋門的閾值**。
而且——**一個估計量的雜訊尺度不能拿另一個估計量的雜訊尺度去推**。
bootstrap 是在「hi/lo 由資料決定」下重抽樣，置換是在「hi/lo 隨機指派」下重抽樣，兩者的變異數沒有理由相同。
本輪的門檻是拿前者去釘後者，錯了 1.79 倍，而 1.79 倍就足以讓門變成裝飾品。

## 四、事後觀察（**post-hoc，不是判決，收官不得引用為結果**）

⛔ R488 的 `real ratio=1.8652 CI=[1.6844,2.1051]` **本輪仍然不可引用為結果**，這一點沒有改變。

但階梯本身透露一件對下一輪重要的事，照實記下來、並標明它**不是**判決：

**假如**錨點 A 通過（它沒有），同一份資料在不同 B 下會給出**相反**的判決：

```
  B =   60 s  ->  PERIOD_CONFOUNDED     (0.6782 >= 0.6234)
  B =  300 s  ->  PERIOD_CONFOUNDED     (0.6258 >= 0.6234，差 0.0024)
  B =  900 s  ->  CONCURRENCY_TAXES     (0.6144 <  0.6234)
  B = 1800 s  ->  CONCURRENCY_TAXES     (0.5720 <  0.6234)
```

**翻面點落在階梯的內部（300 s 與 900 s 之間），不在兩個錨點上，而且 300 s 那格的差距只有 0.0024。**
⇒ **沒有平台**。預註冊挑的 `B=1800` 一格**承擔了全部的答案**。
這正是預註冊裡點名的那個風險（B 的兩個極端會強制相反的判決），
量出來之後可以說得更精確：**它不只在極端會翻，在可用範圍的正中間就會翻。**

⇒ **下一輪不可以只是「把錨點 A 放寬然後宣布 `CONCURRENCY_TAXES`」。** 那會是拿一格挑出來的 B 當結論。

## 七、擋門順序的修復：成立，而且是真的改了行為

- 語意：混淆能**製造出**一個關聯，不能**製造出關聯的不存在** ⇒ 安慰劑只守 CI 排除 1.0 的宣稱。
- 合成復現：`8d6575f`（先於判準 commit）——真值為零時 R488 的順序只有 3.4%–49.9% 會給出正確的 `NO_TAX`，
  而且**真實估計越乾淨，正確率越低**。
- selftest 直接把「同一組輸入」餵給兩個版本，證明差異是真的不是裝飾：
  `R489.decide(...) == "NO_TAX"` 而 `R488.decide(...) == "PERIOD_CONFOUNDED"`。
- 同時擋住了兩個副作用：新增 `TAXES_BELOW_MARGIN`（顯著但小於實用邊際，**仍要過安慰劑**，
  不被 `NO_TAX` 吞掉）與 `SPEEDUP_ANOMALY`。11 個判決**每一個**都有一組輸入到得了（selftest 斷言）。

⚠ **這個修法自己的代價（預註冊就寫了，不是事後補的）**：`NO_TAX` 現在不經過安慰劑
⇒ 本判準**無法排除**「真的有稅、但被一個反號的期間混淆遮蓋成虛無」。引用 `NO_TAX` 時必須連這句一起寫。
本輪**沒有**引用到 `NO_TAX`，所以這個代價這輪沒有被兌現。
