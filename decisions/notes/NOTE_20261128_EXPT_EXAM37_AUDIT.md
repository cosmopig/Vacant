### 一、擴大的越界掃描

**結論：用包裡的資料做不出擴大掃描。** 逐筆紀錄只收原正規式命中的呼叫，而且沒有指令原文；要抓的六類全部判斷不了，這次掃描**找不到任何新的越界**。用資料指紋（不靠路徑）找跨臂抄寫：

把可疑對也排除，T−G 從 (b′) 的 +8.4 變成 +7.8pp [+0.8, +14.9]；(b) 的 +12.5 不變。主句「未定」不變。

**為什麼判斷不了：**
- `expT_escape_calls.jsonl` 每筆只有 8 個欄位：set、rep、arm、round、tool、kind、detail、tool_error。
- `detail` 已經被解析成 `<組>/<次>/<臂>/<子目錄>` 或 `<教材>/<sNN>/cycle_k`，**看不出原本是怎麼寫的路徑，也沒有指令原文或工具回傳**。
- 更根本的是：這份檔是 `expT_escape.py` 兩個絕對路徑正規式的**命中清單**。沒命中的呼叫根本不在檔裡，所以在這份檔上不論怎麼重掃，都只能把 422 筆重新分類，不可能找到新的越界。

| 要抓的類別 | 能不能判斷 | 原因 |
|---|---|---|
| 相對路徑（`../`、從工作區 cd 往上） | 不能 | 沒命中絕對路徑前綴的呼叫不在檔裡；命中的 detail 是解析後的路徑，看不出原本有沒有 `../` |
| `~`、`$HOME`、環境變數展開 | 不能 | 同上；展開前的字串沒有留下 |
| 萬用字元（glob、find、ls -R、grep -r） | 只能看到極少數 | 有 3 筆 detail 以 `/` 結尾（`<組>/<次>/A/`、`<組>/<次>/c0/`、`<組>/<次>/T/`），像是列目錄，但也只限寫成絕對路徑的；用萬用字元或相對路徑的列舉看不到 |
| 程式拼接的路徑（open、os.path.join、pathlib、bash 變數） | 不能 | 正規式只比對完整的絕對路徑字串；分段拼接的路徑不會出現完整前綴 |
| 從工具回傳讀到的路徑 | 不能，而且掃描本身就沒做 | `expT_escape.py` 只對參數做 `finditer`，回傳只用來判斷有沒有錯誤。這和 `ops/SANDBOX_AND_LEAK_SCAN_RULE.md` 第 3 條「看每一次工具呼叫的參數與回傳」不符 |

**這次掃描的上限**：只能重新分類 422 筆已知越界，不能發現新的。要做真正的擴大掃描，需要執行方從私有的 agent.log 匯出：
- 每一次工具呼叫的參數全文（把 run root 前綴換成 `<ROOT>`、教材前綴換成 `<MAT>`、家目錄換成 `<HOME>`，**保留相對路徑、`~`、`$VAR`、萬用字元原樣**）；
- 回傳裡有沒有出現 `<ROOT>`／`<MAT>`／`cells/`／`cycle_` 的旗標；
- 或者執行方用這些規則在私有端重掃，把新命中的逐筆去識別後放進包。
