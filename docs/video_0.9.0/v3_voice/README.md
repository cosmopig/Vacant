# v3：重寫台詞、配音分角色、情緒起伏

畫面沿用 v2（`../v2_3d/`），改的是聲音與文字：

- **台詞重寫**（`clips.json`，一句一個片段，每句各自設定語速／音高／音量）：
  開場用問句（「……真的嗎？」）、「契約？設定？金鑰？——都不用。」、五項檢查改成一連串越問越急的問句、
  結尾獨白放慢壓低，最後「Vacant。」落在重擊上。數字一律和條件同框，口徑照 CHANGELOG 0.9.0。
- **兩個聲音**：旁白 zh-TW-HsiaoChen；agent 的「做完了。」用 zh-TW-YunJhe＋機械感處理（帶通、飽和、短延遲）。
- **逐字對齊**：`anchors.json` 由 edge-tts 的 WordBoundary 算出，畫面上的動態字、agent 圖示、長條、珠串都跟著念到的字走。
- **情緒曲線**（`audio3.py` 的 `AUTO`）：整體音量自動化（連人聲一起）＋段落編曲——
  開場不安 → 憋氣靜音 → 燈亮爆開 → 律動 → 「都不用」停拍 → 堆疊 → 「直到——」全靜 → 凍結心跳 →
  五問加速爬升 → 失敗驟停 → 解決（轉大調）→ 數字推高 → 獨白 → 終局。
  響度範圍（EBU R128 LRA）1.8 → 8.6 LU，整體 −14 LUFS、峰值 −0.9 dBFS。

重建：`python3 tts3.py`（需要網路）→ `python3 audio3.py` → 量 I 後用 `volume`＋`alimiter` 正規化（**不要用 loudnorm 的動態模式**）
→ `render3.py`（同 v2，要 `cues.json`／`anchors.json` 在同目錄）。
