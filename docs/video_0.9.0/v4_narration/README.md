# v4：旁白一條錄完、唸音經過驗證

v3 的回饋：除了「做完了」之外聽起來像多個人、速度忽快忽慢、有字唸錯。這版的做法：

- **一條錄完**（`take.py`）：整段旁白用同一個聲音（zh-TW-HsiaoChen）、同一個語速（+10%）、不調音高，一次合成，
  再依逐字時間切成句子放上時間軸。句中過長的停頓剪短（只剪靜音，不動語音）。每句音量正規化到同一位準（差 0.3 dB），
  同一個殘響，人聲不跟著音樂自動化起伏。
- **不唸英文**：中文聲音唸 Claude、Vacant 不準（ASR 聽成 Clog），名字只出現在畫面上。
- **發音驗證**（`pron.py`）：faster-whisper medium 逐句聽寫，pypinyin 逐音節比對（含聲調）。換掉的詞：
  金鑰→憑證（聽成「驚訝」）、簽章成鏈→簽名串成一條鏈、你得→你要（得被唸成 de）、補回來→差別來自（聽成「不回來」）、
  答對率→正確率（聲調）、四成二→百分之四十二（聽成「四乘二」）。最終 16 句全部通過，見 `pron_report.json`。
- **成品音軌再驗一次**（`mixasr.py`）：混好音樂後逐句聽寫，抓出被音效蓋住的字（彈出音效壓在「照常」上、
  最後一擊的風聲蓋住「讓」、重擊蓋住 agent 的「做」），移開後 18 句全部辨識正確。
