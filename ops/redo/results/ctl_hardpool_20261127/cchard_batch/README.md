## 缺陷與偏離（照實）
- 偏離修正 5 的選擇規則（A 校準 89.7% 在帶外）；已標示。
- 啟動器被背景時限殺一次、額度中斷一次；兩次都靠續跑補，作廢格保留。額度中斷期間（07:19–07:44Z）的 51 格被重跑，重跑格是在較晚時間、與另一位執行者的 Haiku 校準共用機器與額度的情況下完成，**負載與時間不同**。
- 同期容器上還有別人的 Haiku／Devin 批次共用 4 CPU；序列重評分把評分計時雜訊去掉，但**批次內驗收計時雜訊無法移除**（0 次逾時型失敗被近似偵測到）。
- 這個批次**沒有鑑別力**：天花板（A 93%）、幾乎沒有重開（4%）、控制器只觸發 7 次；C 對 B／R 的 0／＋1.7 pp 是 1 對 1／1 對 3 個格的差。
- cchard 的測資是資料庫的變異小輸入（無大規模測資），題目難度被壓平；訓練資料暴露無法排除。
- 弄壞比 0/…：沒有任何曾通過的驗收測試在交付版弄壞。
- 憑證掃描只涵蓋批次與作廢根，不含校準根。
- 延伸：這是最後一個 Haiku 正式批次；之後沒有再開任何 Haiku 批次。
