## 3. 可離線重算 vs 不能（與上下界取法）
| 項目 | 可否純離線重算 | 說明與上下界取法 |
|---|---|---|
| 出處覆蓋率（全宣稱／初稿正確者）與平均候選頁數 | **可** | 對既有 `c0` 報告與補回 gc 頁後的出口紀錄重跑 `plain_contains`＋`matching="b24"`。 |
| 各週期選取清單（`unchanged`／`changed`／`no_source`）、量具漏選率、不必要交辦率 | **可** | 對每週期快照重算哪些宣稱會被選去重查，對照答案鍵得「該重查卻沒被選到」比例與不必要交辦拆解。 |
| 既有報告依 `score_d2` strict＋誤判率 ≤5% 欄位之重評（`a`、`b`、`d_diff_real`、原 `cV5`） | **可** | 依 `1057a6ffb` 與 `field_error_rates.json` 排除誤判率 >5% 之 24 個欄位，以 `score_d2` strict 模式純重評已存報告，另報全欄位版（strict）作對照，不變動任何互動紀錄。 |
| 新選取清單下的實際 agent 行為、越界刪行與退回次數 | **不能** | 當時 agent 收到的交辦由舊量具決定；反事實下其讀頁、改寫與重試行為不可離線重建。 |
| 修正量具下 `cV5` 實測漏抓率與漏抓差（`cV5 − b`、`cV5 − d_diff_real`） | **不能（給上下界）** | 令 `M`＝新量具漏選數、`K_fail`＝原已交辦仍未改對數、`N_add`＝原未交辦但新量具選中之改動宣稱數。**純量具最小下界**＝`M / 分母`；**反事實區間**：樂觀下界 `(M + K_fail) / 分母`（設 `N_add` 全改對）、保守上界 `(M + K_fail + N_add) / 分母`（設 `N_add` 全未改對），並註明交辦清單變動對原改對項之連鎖影響不可離線觀測。 |
| 修正量具下 `cV5` 實際重查花費與成本比（`b/cV5`、`d_diff_real/cV5`） | **不能（給上下界）** | 新選 0 行之週期上下界皆計 0。有交辦週期：**成本下界（最省）**取 `原 cV5 成本 × min(1, 新選行數 / 原交辦行數)`（不低於同組非零週期最小值；原未叫 agent 者亦取該最小值）；**成本上界（最貴）**若新選 ≤ 原交辦取原 `cV5` 實測成本，否則取 `max(原 cV5 成本, 同組有交辦週期最大值)`（上限為同週期 `b` 成本）。由此換算兩成本比區間。 |
