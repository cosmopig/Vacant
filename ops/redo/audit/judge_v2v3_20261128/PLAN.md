## 步驟 0：錯行分類（每個錯行只歸一類，依序判）
0. **K 量具等值**（第二個正規化器判「其實符合答案」；量具問題、不是判定的錯）：
   - K-年齡：答案去掉 `;? N years ago`（`\d+\s+years?\s+ago`）後 `canon_strict` 等於值的 `canon_strict`。（發現：公司組「Founded／Foundation」答案鍵附帶「N years ago」，正確年份一律被判錯。）
   - K-代號：欄位是「Traded as」，值裡抽出的（交易所, 代號）對（`EXCH: TICK` 或 `TICK (EXCH)` 兩種寫法，交易所大小寫不分）非空、且全部屬於答案抽出的對。（答案附帶「S&P 500 component」之類指數成分文字，值只寫代號。）
   - 解析失敗（`canon_parsed=false`）且合 K 規則者記 **U-等值**；解析得出且合 K 規則者記 **K-等值**。兩者合稱「量具等值」。
1. **U 解析失敗、不等值**：`canon_parsed=false` 且不合 K。
2. **S 舊修訂**：值的 `canon_strict` 等於答案鍵任一較晚修訂（k≥1）的 `canon_strict`。
3. 頁面比對（只用該格 agent 抓過、出口 200 的凍結頁；HTML）：
   - **R-單位**：值與答案的數字只差比例尺（×10^3k）或四捨五入（答案有效位數下相等），且值的數字出現在抓過的頁上。
   - **R-部分**（規格外追加，事前寫定）：值的文字是答案文字的真子字串（去空白後），且出現在頁上（例：只寫了進球「(13)」沒寫出場）。
   - 在 HTML 表格（含 infobox）中找含值的儲存格與含答案的儲存格（比對＝去空白、去千分位後完全相等，或答案儲存格的 `(x)` 部分）：
     - **R-欄**：同一列（同一個 `tr`）、不同欄。
     - **R-期**：同一表、同一欄位置（第 i 個 `td`），不同列。
     - **R-他處**：值在頁上（`plain_contains`，或數字正規化後在頁上），但不屬上兩類（別的表、內文、別人的列）。
   - **F 頁上沒有**：值不出現在任何抓過的頁（`plain_contains` 與數字正規化都沒有）。
4. 每類隨機抽 20 行（不足全取；種子 20261128）人工核對，報一致率。

## 步驟 1（步驟 0 推上後才跑）
- **V1**：已有，不重跑。
- **V2**：輸入＝頁面文字（同 V1 的截斷規則）＋欄位＋**口徑**（只用 agent 看得到的任務文字：模板行與 manifest 欄位標籤）＋**值在頁上出現處的那一列**（表格：整列＋表頭文字；內文：前後各一句；值不在頁上就不送、直接給分 0，記 F）。同請求兩題 Noul：q1「這一列／這一段是不是在描述 {實體} 的 {欄位}？」q2「它給的值是不是 {值}？」主分數＝p(q1)×p(q2)。多處出現時取第一個表格處，否則第一個內文處。
- **V3**：Choice「頁上哪一段在回答 {實體} 的 {欄位}？」選項＝值出現處與欄位標籤關鍵詞（同 V1 截斷規則的關鍵詞）出現處的候選段（表格列或內文句；去重，最多 254 個）＋「都不是」；第二段在程式裡比對被選段是否含值（同一套數字正規化）。主分數＝被選段機率 ×（含值 1／否則 0）。
- **機制對照**：每個對的行，把欄位換成同實體另一欄（答案不同；依 claim id 排序取下一個符合者），再問 V1 與 V2；報換欄後 p≥0.9 的比率。
- **主結果**：公司組 AUC(V2)−AUC(V1)、AUC(V3)−AUC(V1) 的配對差，組群集 bootstrap 10,000 次（種子 20261128）；足球組同樣的差。AUC 的標籤＝「錯」、分數＝1−p。
- **主分析排除量具等值（U-等值＋K-等值）**；另報「只排除 U-等值」（規格字面）與「不排除」兩版。
- 門檻（事先定、不掃）：p<0.5；以及足球組讓 V 的標記率等於 V1 在 p<0.5 時標記率（15.7%）的門檻（V2、V3 各自在足球組求得），原封套到公司組。報召回與放行錯誤率。
- 依步驟 0 類別分層的召回；ECE（15 等寬箱）、Brier。
- **過關**（事前）：公司組 AUC 區間下界 >0.5 且相對 V1 差的區間下界 >0 ⇒ 欄位對齊問法有效；足球組相對 V1 差的下界 > −0.03 ⇒ 沒變差。兩條都過才建議換問法。
