# Task

Are there any outliers in the average wait time for callers before being answered by an agent? If so, how many outliers are there?

## Constraints

Detect the outliers using the Z-score method. Consider any data point with an absolute Z-score value greater than 3 as an outlier.

## Answer format

@num_of_outliers[number_of_outliers] where "number_of_outliers" is a non-negative integer value representing the number of outliers detected based on the Z-score method.

## Data

The data file for this task is `data/20170413_000000_group_statistics.csv`.
