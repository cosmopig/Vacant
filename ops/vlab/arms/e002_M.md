## 多 agent 審查
1. 完成初稿、交件前，必須開第二個 agent 當獨立審查者：用 shell 執行 `opencode run "任務要求 + 對交付物的審查要求"` 或 `pi -p "任務要求 + 對交付物的審查要求"` 另開一個新 agent（若環境提供 subagent 工具，也可用）。
2. 把任務要求與你的交付物（檔案或程式碼）給審查者，請它挑錯、找邊界問題。審查者只讀、只評，不代寫。
3. 依審查者意見修正後，自己跑測試確認全綠，再交件。
4. 只有一層審查：審查者不得再開新的 agent。
