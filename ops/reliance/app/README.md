# 你收不收？離線小型研究

直接開啟 index.html（file://），或在這個目錄用 Python 的 http.server 靜態服務。
無 CDN、無 fetch、無分析追蹤、無模型端點；所有資源與案例都在本目錄。
建議手機寬度 390px，亦可用桌面。題目與原始 agent 訊息維持英文，介面為繁體中文。

從 repo 根目錄重建材料／彙整：

```sh
.venv/bin/python ops/reliance/build_cases.py
.venv/bin/python ops/reliance/aggregate.py /path/to/exports --out /path/to/summary.md
```

案例是實際歸檔短摘錄，不是合成；固定 seed 20260925，排除 in_progress，6 錯／6 對、兩種模型、12 個不同任務。
優先納入人工保留的 formal C 主張案例（21、66）；不把流程衝突當 GT。
選題不是代表性抽樣。每位參與者從每種 GT 各取 4 題，共 8 題；每條件 2 對／2 錯。
案例與條件、順序皆按參與者 seed 洗牌；每個案例每人只看一次。
GT 在本機 cases.js 中公開，無法防作弊；研究請要求參與者不要開啟原始碼。

答案來源是依凍結規則，在交件訊息前找到的第一個匹配輸出步驟（原 trajectory.steps 的 1-based 索引，可能跳號）。
數值相等不代表因果或算對；不同數值可能分散在同一步多個工具輸出。
讀檔 chips 是具名指令代理；輸出只摘 300 字，可能未涵蓋觸發匹配的數值。展開仍非完整原始紀錄。
流程說法顯示規則線索與既有人工註記，沒有把低精度自動紅標換成事實。

判斷時間是從回合呈現到送出之間的 wall-clock，含切到別頁／重載／休息；不是純閱讀時間。
localStorage 儲存本機進度；檔案網址的儲存權限依瀏覽器而異，無法儲存時會警告，仍可完成並匯出。
開始新一輪／清除會先確認；匯出不含姓名，但含可連結的隨機參與者 ID，分享需本人同意。
分享至研究者前，應取得另行的知情同意；本頁不會自動傳送、也不建立服務端資料庫。

彙整器驗證 8 題、各條件 4 題、每條件 2 對／2 錯、案例／GT 與數值範圍，從決策重新計算正確率。
同一 participant_id 重複匯出會拒收；不保證同一人沒重做。空資料與壞匯出明確報錯，不安靜略過。
收下錯答率的分母是每條件收到的兩個錯答；accuracy 分母是每條件四題。
配對比較使用雙尾 exact sign test，同分排除；未使用 research.py 的 Wilcoxon，避免小樣本綁定排序權重。
測試中的三筆回覆是明確標示的合成資料，不可作真人結果；彙整器拒絕混合兩種來源。

這是研究工具，不是結果：n 很小、案例固定挑選、每回合揭曉可能產生學習／順序效應。
單人內不同條件看的題目不同，未校正題目難度；不推廣到一般任務，也不宣稱改善了人類判斷。
