# 固定規則：受測 agent 一律關進沙箱，越界掃描是每一批的必要檢查（2026-11-28 起）

**為什麼**：實驗 T 的探索批次（9B、本機）裡，449 次 agent 執行有 45 次讀了工作區外的檔。讀到的有私有教材目錄的未來版本頁面、別組的頁面、紀錄算出的標記 `flags.json`，還寫到共用初稿的快照，判讀之後才被發現（`decisions/conclusions/CONCLUSION_20261128_EXPT.md`）。之前 D2′ 與實驗一的本機批次靠「不可列舉目錄」，不是沙箱。Colab 上的 redo 批次也沒有沙箱。

## 規則
1. **沙箱**：所有受測 agent 都在 bwrap 裡跑，只掛自己的工作區、紀錄目錄、設定，以及唯讀的執行環境（pi、node、venv、/usr、/etc）。題庫、教材、答案、隱藏測試、run root、別的格都不掛。
   - redo（程式題）：`ops/redo/bwrap_agent.sh`（`redo-bwrap-agent`）。
   - 實驗 T 系列：`ops/d2/run_expT.py` 的計畫欄位 `"agent_sandbox": "bwrap"`（`ops/d2/bwrap_expT_agent.sh`）。
   - 沒有 bwrap 的環境（例如 Colab VM），要在預註冊裡寫明「無沙箱」，並且把越界掃描當成作廢依據。
2. **冒煙**：新的沙箱設定第一次用，先用 1 組已用過的資料冒煙（不進正式資料），確認三件事：
   - 紀錄照常產生（掛鉤、標記數合理）；
   - 抓頁面仍經過來源伺服器與出口紀錄（access log 有該臂的請求）；
   - 越界掃描 0。
3. **越界掃描是必要檢查**，看每一次工具呼叫的參數與回傳，不只看指令字串：
   - redo：`ops/redo/analysis/scan_redo_leak.py <root>`。
   - 實驗 T 系列：`ops/d2/expT_escape.py <root> --out-dir …`。
   - D2 教材：`ops/d2/scan_leak.py`。
4. **作廢與排除**（寫進每一份預註冊）：
   - 共用初稿（或單次執行的臂）有越界：那一組作廢重跑。
   - 回饋輪有越界：整對排除，並報「全部」與「排除後」兩個版本。
   - 排除後判定的區間下界不再 >0：主句寫「未定」。
5. **稽核包**要附越界掃描的逐筆結果（去識別：只留格、輪、類別）。
