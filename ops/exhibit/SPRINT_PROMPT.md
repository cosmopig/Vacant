# 這一輪：把展件做到可交付

你是 Vacant 展件的執行端，跑在 Ubuntu VM 上。**每一輪都是全新 session，沒有記憶**——
連續性靠 `~/vacant/EXHIBIT_STATE.md`。

**驗收：2026-08-19 由人類看畫面判斷。要求是「3A 大作等級」。**

## 開場（不准跳過）

1. 讀 `~/vacant/EXHIBIT_STATE.md`
2. `cd ~/vacant/Vacant && git pull` — 讀 `ops/exhibit/PLAN.md`（計畫與已量出的限制）
3. `git -C ~/vacant/vacant_hm pull`
4. 驗身分：`hostname` 應為 `user1`；`ls ~/vacant/bin/genimg.sh` 必須存在

## 你有三個算力，形狀不同（都實測過，不要重測）

| 資源 | 怎麼用 | 額度 | 硬限制 |
|---|---|---|---|
| **codex** `~/vacant/bin/genimg.sh <輸出> <提示詞>` | 生素材，主力 | 看容量 | 沙箱寫不進指定路徑（腳本已接住）；**複雜場景會服務端逾時**——整棟建築剖面連續失敗 4 次 ⇒ 拆小 |
| **K3 看圖** `python3 ~/vacant/Vacant/ops/exhibit/vision.py <圖> <檢查項>` | 畫質品管 | **有限，要省** | 只看通過前兩關的 |
| **本地 qwen** `python3 ~/vacant/Vacant/ops/exhibit/judge.py "<問題>"` | 文字判斷 | **無限** | 30 tok/s、**看不到圖**、推理佔 58–92% |

**省 K3 的規則**：像素量測 → 本地文字判斷 → 才輪到 K3。每次 K3 呼叫要有理由。

## 這一輪做什麼——按這個順序，不要跳

**產線已經定案**，讀 `ops/exhibit/DECISION_PIPELINE.md`（三個實測都有圖可對）：

> **背景＝一次生一整排房間的單張圖**（不是分開生再拼——那條實測失敗了）
> **＋ 獨立生成、淹沒填色去背、縮到統一尺寸的角色貼上去。**
> 樓層＝多張排圖上下疊。

**不要重測已經測過的事。** 已知：分開生拼不起來、一次生一排就一致、
`-transparent white` 會吃掉主體身上的白（用 `ops/exhibit/cutout.sh`）、
codex 複雜場景會逾時（拆小）。

### 第一件：把樓層排圖生齊

參考已經成功的那張：`~/vacant/design/raw/floor_upper.png`
（六個房間：寫字／坐著等／走廊抱紙走／**空房**／翻檔案櫃／寫字）。
**它的提示詞在 `/tmp/g3.sh` 的 `floor_upper` 那段——照那個形狀寫，不要重新發明。**

要生的：
- 再兩三張同形狀的排圖（房間內容換一換，**每張至少留一間空房**）
- **一張評審室那一層**：中間偏右一個比較寬的房間，三個人圍桌檢查文件
  （放大鏡／印章／紅筆）。⚠ `floor_lower` 這次生歪了（給了孤零零一個角色），
  要重試並**看圖確認**才算成功——不要看到檔案存在就當成功。

每張生完：640px 縮圖問 K3 `far` 檢查。過了才留，沒過重生。

### 第二件：角色貼圖庫

參考 `~/vacant/design/sprites/`（三個已經成功：瘦小寫字／矮胖抱紙／高瘦坐著）。
提示詞形狀在 `/tmp/sprite.sh`。

要生的：走路數格、遞交、被退件後的姿態、蓋章、拿放大鏡。
**每個都要體型不同**——剪影辨識度是展場距離下唯一還看得見的東西。

生完一律過 `cutout.sh`，然後**貼在深色底上看一次**確認沒破洞。

### 第三件：把它動起來

排圖當背景，角色貼上去，做一個會動的頁面：人換姿態、一件交付從左移到評審室、
蓋章或被紅筆劃掉。**先做一格會動，再做一排。**

角色要加**接觸陰影**（貼上去沒有影子會浮起來）——那是合成必要的一步。
