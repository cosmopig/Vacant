### 第一件：讓量測有訊號

方向（你自己判斷取捨，不要全做）：

- **加大 n**：378 題裡一定有難題，6 題只是抽樣沒抽到。先跑 `--arms OFF --n 60`
  看 OFF 的失敗率——**OFF 失敗率在 20–60% 之間，才是可用的量測窗口。**
- **換更弱的 worker**：`brain_cline.py` 的 `POOL` 有 hasty-1/hasty-2。
  若整池都太強，考慮只用 hasty 那組當 worker——**但要記錄這是實驗條件的改變。**
- **調難度**：MBPP+ 的 `plus_input` 是加強測資。確認 `hidden_check` 真的用了它
  （用了才難）。

**先量 OFF 的失敗率，那個數字決定後面所有事。** 別的都先不要動。

## 長跑的實驗不要綁在這一輪裡（2026-08-24 實測）

後端是 **8765 算力中轉**（兩台電腦的算力匯集；**不要直接打 1234**，
那是 LM Studio 自己的埠，繞過中轉會跟它的派工撞在同一張卡上）（`http://100.119.113.56:8765/v1/chat/completions`，

```bash
VACANT_EVALPLUS_PATH=.vacant-private/evalplus/MbppPlus-v0.2.0.jsonl.gz \
VACANT_GAIN_API=http://100.119.113.56:8765/v1/chat/completions \
CLINE_KEYS=/nonexistent \

  --models qwen/qwen3.6-35b-a3b,nvidia/nemotron-3-nano-omni --request-timeout-s 600
```

**暖機後每筆約 10 秒**（實測 8 筆連續 0 失敗）。**第一筆會是 146 秒的冷啟動**
——不要拿第一筆去估速度，那會讓你得出「中轉比較慢」的錯誤結論。

- 60 題 OFF ≈ 15 分鐘，ON／OFF5 各 ≈ 1 小時——**ON／OFF5 仍超過單輪上限**。
- 長跑一律 `setsid nohup ... &`，**跑在這一輪之外**。這一輪的工作是
  「啟動它」或「分析它已經產出的東西」，不是「等它跑完」。

⚠ **開跑之前先確認沒有別的 gain_run 在跑**：

```bash
pgrep -af "gain_run.py --out" | grep -v grep
```

有的話就不要再開一個。兩個 run 同時打同一個 LM Studio 會互相拖慢，
而**延遲是實驗條件**（SPEC_GAIN §7）——被污染的延遲數字看起來跟
「模型就是這麼慢」一模一樣。同一個輸出目錄有 runner 的擋門，
**不同目錄沒有**，那要靠這一步。

## 三條不准違反的

1. **OFF5 是誠實與否的分水嶺。** ON 比 OFF 好幾乎必然（多花五倍呼叫）。
   要答的是**等預算下 Vacant 打不打得贏 self-consistency**。
   打不贏也是結論，照實寫。
2. **infra_void 不算成功也不算失敗。** 它是「這一格沒量到」，
   跟「量到 0」必須分得開。分母要對。
3. **評審準確率單獨報。** 評審跟被評審同一個模型家族 ⇒ 共同盲區。
   評審若接近亂猜，ON 的任何增益都不是機制帶來的。

## 這是一個迭代到有成效為止的迴圈，不是一次性任務

「有成效」的定義**先寫死**，不准做完再挑：

   做不到這一步，後面的數字都沒有意義。

## 模型要聰明切換（人類 2026-08-24 指定）

**這一輪結束前，你必須決定下一輪用什麼模型，並寫進交接檔：**

```bash
echo opus   > ~/vacant/NEXT_MODEL     # 或 sonnet
```

`loop.sh` 下一輪會讀它、用一次、然後**刪掉**（不刪的話 opus 會黏住，
之後每輪都用 opus 收數字，那正是要避免的浪費）。**不寫就是 sonnet。**

判準：

| 用 **Opus 5** | 用 **Sonnet 5** |
|---|---|
| 實驗設計的取捨（換題庫？換池子？判準怎麼定） | 跑既定的實驗、收數字 |
| 結果反直覺、要判斷是真發現還是 bug | 寫／改 runner 的程式碼 |
| 寫結論、判斷證據夠不夠 | 整理落盤資料、產報表 |
| 前一輪推翻了自己，要重新判斷 | 重複性的驗證與對帳 |

**預設用 Sonnet。** 只有上面左欄那幾種情況才值得 Opus——
它貴而且慢，用在收數字上是浪費。

**同時在 `GAIN_STATE.md` 寫一行**：`下一輪模型：opus／sonnet ＋ 一句理由`——
檔案是給機器讀的，這一行是給稽核端看的，兩個都要有才對得起帳。
