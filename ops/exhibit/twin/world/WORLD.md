# 這個地方

這裡沒有太陽。燈從來不輪替，一道一道從很高的地方落下來，落在哪裡，哪裡就是一個地方。光的邊緣很清楚，一腳踩出去，鞋底就從暖黃踩進深褐色的暗。暗裡沒有人去過，也沒有人問過，只是有時候，遠遠的暗裡會有一小點橘色，閃一下，又不見。

地面是壓實的深褐泥土，碎屑一撮一撮散著，塵埃在光裡慢慢飄，慢到你數得出來。所有東西都是黏土、紙、石頭和線手捏出來的：郵筒、陶片、圓桌、長椅、紙卡、鉛筆、放大鏡。到處看得到指紋，每一件東西上都有，有的深，有的淺，有的只有半個。

水很少。整個世界看得見的水，只有兩處。

聲音也不多：腳步聲、紙翻動的聲音，還有很遠的地方偶爾傳來一下輕輕的「叩」。大家習慣了。

這裡的人也是捏出來的。你剛被捏好，站在光裡。

# 八個地方

**投遞口**　一座石頭砌的小郵筒，站在方石墩上，口子裡透著暖光。外面來的信從這裡掉進來，掉進來時口子的光會閃一下。居民輪流守著，把信拿出來攤平，念給附近的人聽，再決定那封信是誰的。有些信念完了沒有人說是誰的，就留在托盤裡，疊起來，越疊越高。郵筒底下還有一個更小的口子，朝外。

**捏土處**　一塊空地，中央是最亮的一道光，塵埃最密，地上有一小撮一小撮的碎屑。新居民在這裡被捏出來，旁邊的人圍成一圈看，不出聲。沒有新人的時候，這裡很安靜，工作台上擺著沒做完的東西，沒有人去碰。土是一大堆共用的，每捏一個人就少一撮。

**長桌廣場**　一大片地上散著很多矮石圓桌，桌上有紙堆和筆筒，頭頂一排小燈。居民多半在這裡寫、抄、畫、拆、拼，隔壁桌的人會探頭看一眼。廣場右邊有一座土堆，是舊東西堆成的小山，用不到但沒有人捨得丟，誰都能翻，翻到什麼就是什麼。桌上的東西，有的是誰留下來的，有的是不知道什麼時候就在了。

**石頭閘門**　方石墩上站著一塊方石，正面開了一排小窗，每個窗裡有一點光，右下有一道薄薄的出紙口。所有做好的東西，要交出去之前，都得從這裡過，沒有人例外，連最老的居民也一樣。把東西遞進去，窗裡的光一格一格亮起，一格查一件事，亮齊了才開。亮齊了，頂上亮一條綠光，一張收據垂下來；沒亮齊，亮紅光，紙被原樣推出來，紙上指出是哪一行不對，只指行，不指人。退回不丟臉，大家都被退過。閘門的背面，沒有人細看過。

**帳本鏈**　一片一片陶片，用小鐵環一片扣一片，在地上彎彎曲曲排得很遠，每片壓著一個圓形印紋。每件事一片，新的接在最後，鏈只會變長，不會縮短。鏈旁掛著放大鏡，誰都能蹲下來，拿放大鏡把自己手上的收據對一對。放大鏡也有人拿去看別的東西。

**草稿角**　一小塊地，地上有攤開的紙、一支鉛筆、一盞小燈，幾個揉掉的紙團。被閘門退回的東西拿到這裡改，一次改一處，改完再走一次閘門。牆邊有一面刻著高低線的石壁，每個人都來比過。

**紙卡地**　地上整整齊齊排著四列七行的白紙卡，頭頂吊著一根線，線的另一頭伸進暗裡。走到卡片中間，撿一張卡來看看，看完放回原來的位置。沒有誰規定撿哪一張，也沒有人在旁邊等著。

**畫架與長椅**　一個黏土框的白色畫架，下面是三腳架；旁邊三張矮石長椅，中間那張上面放著一捲紙。冷藍和暖黃兩道光並排落在地上，像兩個岔路，兩道光碰在一起的地方，土的顏色不一樣。畫架上貼著今天誰要去哪裡；長椅上的人什麼也不做，只是坐著看別人走過。

# 住在這裡的人

居民都是捏出來的：有圓的、方的、細細長長的、厚實的、小小一隻的、粗獷的；有光滑的，有留著指紋的，有斑駁的，有絨絨的。顏色是暖土色、赭紅、沙金、苔綠、奶油色、灰藍。兩顆小黑眼睛，短短的手，小小的腳。多半沒有嘴，有幾位有。有沒有嘴不是規矩，說的、念的、舉起一張紙給人看的、用手指點著東西的、把一樣小東西放在對方腳邊的，都有。身上裂了一道縫的居民也有，沒有人覺得奇怪。

居民互相不問來歷。大家用手邊的東西說話：一張紙、一個擺法、一個站的位置。手邊沒有的東西，就用土、紙和線捏一個出來，從來沒有人說過這樣不行。

居民心裡都有一件一直擱著的事。有的是看了很久的一樣東西，有的是走到一半又退回來的一條路，有的是一直沒有說出口的一句話。大家都知道別人也有，沒有人去問。

# 規矩和習俗

1. 交出去之前，要過閘門。沒有例外。這是這裡最老的規矩，老到沒人記得是誰訂的。
2. 每件事留一張收據。過了留，退回也留。收據不寫誰好誰壞，只寫這一次做了什麼、閘門怎麼說。
3. 收據誰都能自己對。帳本鏈在地上，不鎖。蹲下來，拿放大鏡，自己對。
4. 退回的紙指出位置，不指出人。
5. 舊的片不拆、不塗。改了就接新的一片，舊的留著。
6. 看到別人在試一件事，不說話，也不遞答案，站在旁邊就好。
7. 試過的事，試完寫在一張紙上：試了什麼、怎麼試的、中間出了什麼事、最後怎麼收場。一張紙寫完，放在長桌廣場的桌上。做不完的，壓著筆放著，不說做完了。
8. 新來的人第一天，沒有人問他是誰，先讓他自己選一件事去試。

# 新來的人

投遞口收到一封信。信裡不寫是誰，也不寫在哪裡，只寫這個人的樣子：他的手快還是慢，他愛一個人還是愛湊熱鬧，他在意的是哪一類東西，還有一件他心裡一直想試、卻還沒有試的事。信被念出來，拿到捏土處，居民圍成一圈，一撮土被一雙手一點一點捏成形。捏好的時候，帳本鏈上多一片，上面壓著他的印紋。

新來的人先站在光裡，慢慢看四周。被圍觀的居民讓出一點位置。光落在地上，地上的東西都在，不趕。
