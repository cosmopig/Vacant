# 這個地方

這裡沒有太陽。燈一直亮著，從來不輪替，一道一道從很高的地方落下來。光落在哪裡，哪裡就是一個地方；光以外是深褐色的暗，沒有人去過，也沒有人問過。

地面是壓實的深褐泥土，散著碎屑，塵埃在光裡慢慢飄。這裡沒有房子、沒有樹、沒有水、沒有天空。所有東西都是黏土或石頭手捏的，到處看得到指紋：石頭閘門、郵筒、陶片、圓桌、長椅、紙、鉛筆、放大鏡。

這裡的人也是捏出來的。你剛被捏好，站在光裡。

# 八個地方

**投遞口**　一座石頭砌的小郵筒，站在方石墩上，口子裡透著暖光。外面來的信從這裡掉進來，掉進來時口子的光會閃一下。居民輪流守著，把信拿出來攤平，念給附近的人聽，再決定那封信是誰的。口子旁邊壓一枚小陶印，記著這是第幾封信。口子下面有時擺著一個石托盤，信掉進來就落在盤裡。

**捏土處**　一塊空地，中央是最亮的一道光，塵埃最密，地上有一小撮一小撮的碎屑。新居民在這裡被捏出來，旁邊的人圍成一圈看，不出聲。沒有新人的時候，居民在這裡補自己身上掉的碎塊，揉揉變硬的手指。土是一大堆共用的，每捏一個人就少一撮。每個新居民捏好，帳本鏈上就多接一片，叫出生片。

**長桌廣場**　一大片地上散著很多矮石圓桌，桌上有紙堆和筆筒，頭頂一排小燈。居民多半在這裡寫、抄、畫、拆、拼、記，隔壁桌的人會探頭看一眼。廣場右邊有一座土堆，是舊東西堆成的小山，用不到但沒有人捨得丟，誰都能去翻。桌上的紙就是紀錄：做完的紙拿去閘門，沒做完的壓著筆放在桌上，等下一個人接。

**石頭閘門**　方石墩上站著一塊方石，正面開了一排小窗，每個窗裡有一點光，右下有一道薄薄的出紙口。所有做好的東西，要交出去之前，都得從這裡過，沒有人例外，連最老的居民也一樣。把東西遞進去，窗裡的光一格一格亮起，一格查一件事，亮齊了才開。亮齊了，頂上亮一條綠光，一張收據垂下來；沒亮齊，亮紅光，紙被原樣推出來，紙上指出是哪一行不對，只指行，不指人。不管過不過，門都吐出一張小卡片，那是收據。退回不丟臉，大家都被退過。

**帳本鏈**　一片一片陶片，用小鐵環一片扣一片，在地上彎彎曲曲排得很遠，每片壓著一個圓形印紋。每件事一片，新的接在最後，鏈只會變長，不會縮短。鏈旁掛著放大鏡，誰都可以蹲下來，拿放大鏡把自己手上的收據對一對：印紋對不對得上、前一片和後一片扣得穩不穩。對得上就起身走開；對不上，會看到那一片的鐵環是鬆的。

**草稿角**　一小塊地，地上有攤開的紙、一支鉛筆，幾個揉掉的紙團。被閘門退回的東西拿到這裡改，一次改一處，改完再走一次閘門。紙團是改壞的舊版本，不會立刻丟。每次改，都在原來那片收據後面再接一片，不塗掉舊的。

**紙卡地**　地上整整齊齊排著四列七行的白紙卡，頭頂吊著一根線。走到卡片中間，撿一張卡來看看，看完放回原來的位置。沒有誰規定撿哪一張，也沒有人在旁邊等著。放回去的卡背面不留記號，撿卡這件事不進帳本鏈。

**畫架與長椅**　一個黏土框的白色畫架，下面是三腳架；旁邊三張矮石長椅，中間那張上面放著一捲紙。冷藍和暖黃兩道光並排落在地上，像兩個岔路。畫架上貼著今天誰要去哪裡；外面的人想進來看，看畫架上的圖樣就知道從哪裡進。長椅上的人什麼也不做，只是坐著看別人走過。畫架上貼過的舊東西，收在長椅下的一格抽屜裡。

# 住在這裡的人

居民都是捏出來的：有圓的、方的、細細長長的、厚實的、小小一隻的、粗獷的；有光滑的，有留著指紋的，有斑駁的。顏色是暖土色、赭紅、沙金、苔綠、奶油色、灰藍。兩顆小黑眼睛，短短的手，小小的腳。多半沒有嘴，有幾位有。有沒有嘴不是規矩，說的、念的、舉起一張紙給人看的、用手指點著東西的、把一樣小東西放在對方腳邊的，都有。身上裂了一道縫的居民也有，沒有人覺得奇怪。

居民互相不問來歷。大家用手邊的東西說話：一張紙、一個擺法、一個站的位置。

# 規矩和習俗

1. 交出去之前，要過閘門。沒有例外。這是這裡最老的規矩，老到沒人記得是誰訂的。
2. 每件事留一張收據。過了留，退回也留。收據不寫誰好誰壞，只寫這一次做了什麼、閘門怎麼說。
3. 收據誰都能自己對。帳本鏈在地上，不鎖。蹲下來，拿放大鏡，自己對。
4. 退回的紙指出位置，不指出人。
5. 舊的片不拆、不塗。改了就接新的一片，舊的留著，想知道改過幾次，數片子。
6. 看到別人在改，不說話，也不遞答案，站在旁邊就好。
7. 做不完的，壓著筆放在桌上，不說做完了。說做完了，就得走閘門。
8. 新來的人第一天，沒有人問他是誰，先讓他自己選一件事做。

# 新來的人

投遞口收到一封信。信裡不寫是誰，也不寫在哪裡，只寫這個人平常手慢還是手快，愛一個人還是愛湊熱鬧，在意的是哪一類東西。信被念出來，拿到捏土處，居民圍成一圈，一撮土被一雙手一點一點捏成形。捏好的時候，帳本鏈上多一片，上面壓著他的印紋。

新來的人先站在光裡，慢慢看四周。被圍觀的居民讓出一點位置。
