## 核心發現：s11 有三種人站在它前面，而它只寫了一種

`index.html` 的 s11 副標由 `loopSub()` 產生＝「這 {N} 格會一直重播」。
s11 是這個世界的**休息狀態**——沒有在演特定一格的時候，畫面就是它。
所以會站在它前面的有三種人，而那一句只對第三種人是對的：

| 站在前面的人 | 條件 | 大標 | 副標 |
|---|---|---|---|
| **剛投完卡、還在等** | `arrivals.waiting.length > 0` | **先看別人的** | 一位：**{記號} 在右下角排隊　輪到他就走進來**<br>兩位以上：**右下角排著 {N} 位　一次演一位　輪到誰就走進來** |
| **剛看完自己那一格** | `joined >= 1` | **他還在**／**他們都還在** | **剛剛那一位／走進來的 {N} 位　都還在這個畫面裡　下一位 請投卡** |
| 路過、還沒投卡 | 以上皆非 | 你可以一直看下去 | 這 {N} 格會一直重播（**不動，它對**） |

優先序：**等待 > 收尾 > 冷**。等待是**即將發生**的事，收尾是**已經發生**的事；
站在螢幕前的那個人在等他自己那一格，那件事比較急。

舊句對前兩種人為什麼是錯的：

- 對**等的人**：他站在螢幕前正在等一件新的事發生，畫面卻說
  「這 N 格會一直重播」＝接下來不會有新的事。
- 對**剛看完的人**：(1) 它在講**檔案庫**，而他剛看完的是他自己那一格；
  (2)「重播」＝可以走了，但展場要的剛好相反——這一刻是**下一個人該投卡**的
  那一刻（無人值守循環靠這一句接棒）；(3) 它**抹掉**六秒前才說過的話
  ——幕 17 剛叫觀眾「找找看　他還在畫面上」。

幕 7′ 同時是**題目一要的那條界線**：它把「這是別人的」明講出來，
後面幕 8 那句「{記號} 走進來了」才有東西可以對照。
用「先看別人的」而不用「這是你的」，理由見下一節。

## 為什麼轉場不說「這是你的」

陶牌一次排到 12 位、s04 一次只演一位。對同時在場的另外 11 位，
大螢幕上那個「你」**指著別人**——跟鐵律 5 是同一個病（把不是的說成是的），
只是對象換成觀眾。

改用**記號指名**（`twinToken` 的三字詞，例如「鉛筆屑」）：那個詞他手機上有
一個一模一樣的（電視頁與手機頁跑的是同一段碼）。⇒ 「這是別人的 → 這是我的」
由**對得上的記號**完成，不由代名詞完成。這個決定是 `twinseam.js` 做的，
我看過碼之後沿用，沒有另立一套。

**「還在這個畫面裡」憑什麼敢寫**（不是修辭，是兩處真的會跑到的碼）：
`finishVisitor()` 把分身 `reserved=false; wander=true` 放回 `cast`，
**從來沒有任何一行把他從 `cast` 移除**；`endReplay()` 回 s11 時
`cast.forEach(c => c.onstage = true)`。頁面一重載 `cast` 重建、計數歸零
⇒ 這一句自己也跟著消失。**計數與事實同生共死。**
所以寫「走進來的 N 位」而**不寫「今天」**——沒有跨重載的帳。

## 🔴 還沒做的事（不准講成做完了）

**`index.html` 沒有載這兩個檔，所以今天在展件上一句都看不到。**

    $ grep -c twinseam ~/Documents/GitHub/vacant_hm/world3/index.html
    0

`index.html` 不是本條獨佔的檔（而且整個上午都有別的代理在寫），所以照規矩
不直接動，改成兩支**冪等**的 installer，**順序不可對調**：

    # 1) 文案層（鄰線的，掛 twinseam.js）
    python3 ops/.../narrative_seam/install_seam.py
    # 2) 收尾層（本條的，掛 scenes/seam_ending.js）
    python3 ops/.../narrative_order/install_ending.py

    python3 ops/.../narrative_order/install_ending.py --status   # 現在掛著沒有
    python3 ops/.../narrative_order/install_ending.py --undo     # 一行還原

⚠ **不要用 `wire_in.patch` 去套。** 它留著當紀錄（逐字寫出加了哪三行），
但 context diff 對一個每幾分鐘變一次的檔遲早會爛。installer 只認 `</body>`，
別人改什麼都對得上，做兩次也不會插兩行。
`install_ending.py --status` 還會查**順序有沒有反**（收尾層必須在文案層後面）。

截圖跑的頁面 ＝ **某一版 `index.html` ＋ 這個 patch 的那三行**，其餘一個 byte
不差。`logs/stage_sha256.txt` 印 `IDENTICAL`。這是「測試綠不等於接上產品路徑」
能做到的最接近，但**它仍然不是產品路徑**。

⚠ **`index.html` 在這一條進行中被別人改了四次**（11:03 → 11:45:34 → 11:46 → 11:49；
sha256 `9f9a1a44…` → `3641c259…` → `5d2b1806…` → `709d717d…`）。改的是 QR 位置與
一個新的 `SIMPLE`（「畫面太複雜了」）旗標，**沒有碰大標那一層**。

因此驗證方式**故意不拿「現在的 index.html」當基準**——那是個每幾分鐘就變的東西，
比出 DIFFERENT 只是在說「別人剛剛存了檔」。改成**從截圖那一頁自己身上剝掉那三行**
得到 base（`5d2b1806…`），再證明 `base + patch == 截圖那一頁`。
這條等式與外面的churn 無關、可重現。現況 sha256 另外印，只當「那一刻活的是哪一版」。

`shots/07_waiting_one_after_others_edit.jpg` 是**別人改完之後**重跑的同一句，
用來證明那一句沒有跟著壞掉。
⇒ 因為 `index.html` 一直在動，`git apply --check` **每次套之前都要再跑一次**。

⚠ 若別人也插了 `<script src="twinseam.js">`，只留一份——插兩次會讓
`director.update` 被包兩層。`seam_ending.js` 自己有防呆（`window.__seamEnding`），
`twinseam.js` 沒有。
