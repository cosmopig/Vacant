# 可究責追緝（accountable trace）— `/loop` 的錨

⚠ **每一輪 `/loop` 一開始先讀這一份＋`PROGRESS.md` 的尾巴**，再決定這一輪做什麼。
這份檔的用途是**防止偏移**：做任何事之前先對照 §一 與 §二；對不上就不做。

## 一、目標（人類原話，2026-09-24 晚上）

> 最後我們要讓使用者的體感是「**讓產出越趨近於需求**」，也就是最終我們要**影響繳付物**——
> 不是隨便 AI 說什麼算什麼，而是**一個至少經過一連串的追緝**；就算有問題，**最後也應該要提出問題**，
> 而不是被上下文淹沒之類的。所以我們看到過去我們單獨測試 vacant，它的 token 雖然翻倍，
> 但最後的題數答題的效果也更好，這就是我們要的。

> （更早）這完全不是我要的東西……agent 不一定是用來寫程式……你現在的這個版本是讓本機多個
> 可以去驗證的驗證器，**並非是咎責且抓出錯誤點的東西**。

人類對四個問題的回答：咎責對象＝**步驟與 agent 兩者都要**；錯誤點＝**追到造成錯誤的那一步**；
後果＝**信譽＋路由**；使用情境＝**人直接用一個 agent**（Claude Code／Codex／OpenCode／pi）。
其餘取捨：「一定沒有最佳只有你想怎樣取捨……我以你們的答案為主直接去做」。

## 二、這個版本要做到的（驗收時逐條對）

1. **病歷**：agent 工作的每一步（工具呼叫、讀、寫、跑、派給子 agent）都落進簽章鏈，
   帶行動者（平台、主／子 agent、模型）。沒被記錄到的改動標成**究責缺口**，不假裝完整。
2. **抓錯誤點**：檢查（契約驗證器，或人指出「這段錯了」）失敗時，**追到寫下錯誤內容的那一步**、
   那一步當時讀了什麼、錯誤源頭是誰（agent 自己／子 agent／輸入資料或需求／工具輸出），
   證據**可重驗**（重跑檢查在「那一步之前過、之後不過」），**不靠模型意見**。
3. **影響繳付物（增益）**：追緝的結果以**事實**回給 agent（哪裡錯、哪一步寫的、錯的值從哪裡來），
   讓它在交件前改到根源；改不掉的，交件時**明確列出未解問題**給使用者，不被上下文淹沒。
4. **後果**：責任按行動者累積 → 信譽 → 路由（誰拿到下一件工作）。只有可證明的過錯才重罰。
5. **四個 agent 都成立**（pi／Claude Code／OpenCode／Codex），用真的 binary 量。

## 三、不准違反的原則（出自 0924 論文，改之前要寫理由）

- **執行取代意見**：錯誤點由重跑與紀錄比對決定，不問模型「是誰的錯」（同儕評審準確率 0.7552 對
  「全判通過」0.7522；Who&When 類 LLM 歸因在步驟層很低）。模型判斷最多是**標明的提示**。
- **KS-1**：任何給 agent 的文字不准有「你有責任／會被懲罰」；後果只走路由、經驗、交付處理三條
  非文字通道。回饋只陳述事實。
- **誠實邊界**：竄改可察覺≠不可竄改；自己記自己的紀錄有結構弱點；完整性≠完備性；沒量到≠零；
  用「可究責性」不用「信任」；不說「不會被繞過」。
- **究責鏈接回人**：誰訂的判準、誰選的 agent、誰批准的。
- **不偏題**：模型通道中介（possess／enclosure／tier）不是這次的主題；不動凍結項
  （`reputation.slash` 的語意、B 層六情境、gateshim 21／23）。
- **沒有真模型 API**：這個環境只有假模型＋真 agent binary ⇒ 今晚的證據是 **L-fake 機制層**；
  真模型增益寫成預註冊實驗交給團隊跑，不准宣稱已量到增益。

## 五、每一輪的做法

1. 讀本檔＋`PROGRESS.md` 尾巴＋背景工作的通知（workflow、agent）。
2. 挑**第一個沒勾的里程碑**（被擋住才跳下一個，並在 PROGRESS 寫原因）。
3. 做；實質工作用 workflow（ultracode）；改碼要有測試。
4. 驗：`.venv/bin/python -m pytest <相關測試> -q`、`ruff`（CI 那組）、`mypy`（CI 那組）、
   `ops/check_repo_links.py`；全套測試在里程碑結束時跑一次，失敗集合要等於基線
   （5 個 cert selftest＋5 個 exhibit-twin 環境錯）。
5. commit（附 attribution 兩行）＋ push 到 `claude/vacant-verification-redesign-jv7eou`。
6. `PROGRESS.md` 追加：做了什麼、證據、下一步、偏移檢查（對 §二 哪一條有貢獻）。
7. 排下一次喚醒（背景工作在跑就用長的後備間隔，靠通知叫醒）。
