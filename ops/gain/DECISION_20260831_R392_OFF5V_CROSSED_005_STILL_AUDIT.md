# DECISION — round392：off5v 的 p 值跨過 0.05，但這不是新發現，是 round388 歸因的預測結果

## 觸發

round391 交接寫死了一個推翻/確認條件：「off5v 的 `(b,c)` 若首度偏離
`(0,5)`，優先重算 p 值」，並具體預告：「只要再出現一個方向不變的
discordant pair（c:5→6，b 仍是0），p 會降到 `2×0.5^6=0.03125`，跨過 0.05」。

round392 快照（n=67 配對）：`(b,c)` 從 `(0,5)` 變成 `(0,6)`，
`McNemar exact p = 0.0312`，`verdict = mechanism_contributes`，
`gap = 8.96pp`。**與 round391 的預告逐位數吻合**（0.03125 → 顯示 0.0312）。

## 這是不是「Vacant 的評審機制真的有效」的新證據？

逐一比對新增的 discordant task（比 round388 的 5 個列表多一個）：

```
$ 手動重算 discordant task ids（leaked = accepted and not meets_demand）
c (off5v_only, n=6): 305, 427, 593, 736, 739, 790
                      ^^^ 新增的是 427，其餘 5 個與 round388 完全相同
```

檢查 `mbppplus_Mbpp/427` 的 ON 那一列：

```
passed_review: true   （3 位同儕評審：hasty-2 raw_pass=false 但 grounded_pass=true
                        算 outside_input_contract；hasty-1/careful-1 都過）
audited: true          audit_ok: false   ← 稽核抽中且判定不合格
accepted: false        ← 最終被稽核擋下，不是被評審擋下
```

**與 round388 找到的另外 3 個案例（305/593/739）同一個模式**：評審全數
放行，真正擋下來的是確定性抽樣稽核（`sha256("audit:"+task_id) < 0.2`）。
audit 的抽樣鍵只吃 `task_id`，跟哪個臂無關，所以 427 在 OFF5 上一樣會被
同一顆種子抽中。

## 用 off5va（把同一道稽核閘離線套到 OFF5）驗證：這一格會不會被吸收

本輪同步重跑 `analyze_off5va.py`（audit-rate 對齊 0.2）：

```
                    round388(n=61)   round389(n=63)   round390(n=64)   round392(n=67，本輪)
off5v  (b,c)        (0,5)            (0,5)            (0,5)            (0,6)  ← 剛跨過顯著
off5v  p             0.0625           0.0625           0.0625           0.0312
off5va (b,c)        (0,2)            (0,2)            (0,2)            (0,2)  ← 完全沒動
off5va p             0.5000           0.5000           0.5000           0.5000
off5va gap           3.28pp           3.17pp           3.13pp           2.99pp
```

**off5va 的 `(b,c)=(0,2)` 連續 4 個檢查點沒有變化，即使 off5v 剛好在本輪
跨過顯著門檻。** 這正是預期中的結果：一旦補上同一道稽核閘給 OFF5，
427 這一格（跟 305/593/739 一樣）就從「c」欄位裡消失，off5va 只剩下
736/790 兩個真正跟稽核／評審都無關的獨立生成雜訊。

## 結論

**off5v 剛跨過 p<0.05 不是「Vacant 評審機制開始顯現效果」的新證據。**
它是 round388 已經確立的歸因（「off5v 的差距主要來自稽核，不是評審」）
在 n 增加後的機械結果：更多題目落入配對池，恰好又抽中一個屬於「評審
放行、稽核擋下」模式的案例，把本來就逼近顯著的原始統計量推過門檻。
**控制稽核之後（off5va），這條線從 round388 到現在完全沒有變化**——
沒有新的顯著性，沒有新的機制證據。

若要對外報告，正確的講法是：「ON 整體優於 OFF5V（p=0.0312，主要由確定性
稽核驅動，該子機制已於 SPEC_GAIN 定義中明載為 ON 臂的一部分——見
round389）；扣除稽核後，殘餘的評審/生成差距（off5va）不顯著且四個檢查點
穩定在同一數字」，而不是「Vacant 的多智能體評審機制顯著優於
self-consistency」——後者會把功勞錯放到評審機制上。

## 對三條「有成效」判準的影響

1. 量測有訊號 ✓（不受影響）
2. 三臂有差異：**off5v 這條輔助線現在正式跨過顯著**（p=0.0312），
   但機制歸因仍是稽核，不是評審——這件事本身**是「有差異」的一個實例**，
   只是要準確描述差異的來源。主判準 ON vs OFF5 仍不顯著（p=1.0，
   round391 的容量上界分析本輪重跑仍是 `required_n≈3852`，同一量級，
   結論不變）。
3. 等預算答案不受影響（仍是 upper-bound-by-design，見 round391）。
