# Task

Take a list of short strings and lay them out as a simple list for a
plain-text note: each entry on its own line, introduced by a hyphen and one
space.

There is no line break after the last entry, and a list without entries gives
text with nothing in it.

## Interface

    bullets(items) -> str

Write the code in a file called `solution.py` in this directory.
Nothing else is needed and nothing else is read.
