## 為什麼一定要做 Q2（`analyze_off5_persona.py` 的結構性盲點）

`arm_off5` 抽籤是 `[rng.choice(agents) for _ in range(k)]`（**取後放回**）⇒ 每個 persona
只出現在部分題目上。邊際通過率因此混淆於「抽到哪些題」。

**量具驗證裡的植入 null 案直接示範了這件事**：造一份**所有 persona 品質完全相同**、
只是 `careful-1` 只被抽到難題的假資料，邊際 Fisher 吐出 **p=0.000954**——
跟 round63 在真實資料上報的 p=0.0009 **同一個量級**。
⇒ 邊際統計量在原理上分不開「這個 persona 差」與「這個 persona 抽到難題」。

## 新工具 `ops/gain/analyze_off5_matched.py`（唯讀，不打端點、不重跑 sandbox）

- **題內配對**：只看目標 persona 有出現的題，比它 vs **同一批題**的其他候選碼 ⇒ 難度消掉。
- **題內置換**（每題內部洗 `agent_id` 標籤、ok 值留原位）：保留每題難度與 persona 出現次數，
  只打斷 persona→品質關聯。統計量取「六個 persona 中最小的 Fisher p」，其置換 p **就是**
  多重比較修正後的 p。

**量具雙向驗證（4 案全過，`--selftest`，正式數字之前跑）**：

```
[植入正案] worst=careful-1 配對劣勢=-100.00pp 配對置換p=0.00020 修正minFisher p=0.00020 => PASS
[植入null案-難度混淆] 未修正邊際 Fisher p=0.000954 (worst=careful-1) <= 混淆造出的假訊號
[植入null案-難度混淆] 題內配對劣勢=0.00pp 配對置換p=1.00000 => PASS
[混合效應 null 案] 品質全同、份額極偏 => +0.00pp => PASS
[混合效應 正案] 全給最差(0.0)、其餘 1.0 => -83.33pp (應 -83.33) => PASS
量具雙向驗證：全案皆過，可用
```

## 實測（11 題 / 53 份候選碼，OFF5 進度 11/60）

```
careful-1 邊際 2/8 25%   careful-2 6/7 86%   hasty-1 11/11 100%
hasty-2   8/10 80%       plain-1   7/7 100%  plain-2 7/10 70%

未修正 min Fisher p = 0.000892   <= round63 報的就是這個（事後選最差，沒修正）
多重比較修正後 p     = 0.015999   (20000 次題內置換)  <= 膨脹約 18 倍

題內配對（只看 careful-1 有出現的 6 題）：
  careful-1        2/8  = 25.0%
  同批題其他候選  14/20 = 70.0%
  配對劣勢 = -45.00pp   配對置換 p = 0.015999
```

- **Q2 成立**：-45.00pp ≥ 15pp 且 p=0.016<0.05。
  但注意：原始 75pp 落差裡**約 40% 是抽題運氣**（75→45pp），邊際數字確實高報了。
- **Q3 成立**：修正後 p=0.016<0.05。

### ⚠ 兩條必須跟結論一起讀的限制（不是事後找的藉口，是量出來的）

1. **Q2 與 Q3 在這份資料上是同一個檢定，不是兩次獨立確認。**
   逐次比對 3 個 seed × 8000 次置換，兩個統計量的「是否更極端」判斷
   **8000/8000 完全一致**。機制：置換保留 careful-1 的出現次數 ⇒ 兩個統計量都是
   careful-1 成功數的單調函數。所以 p=0.016 只有**一個**。
2. **這是第四次連續看同一份累積中的資料**（round63 三次 + 本輪一次），
   **沒有做序貫檢定修正**（事前判準沒寫，事後不補）。若對 4 次 look 做 Bonferroni，
   0.016×4 = **0.064 > 0.05**。⇒ 「顯著」這件事本身撐得不寬裕，照實記。

## 主結論：前提錯了，結論仍對，但**理由要換掉**

用 OFF5 品質（獨立於 ON 臂 ⇒ **不是** round61 抓到的 `pooled_CIRCULAR` 那種循環估計）
重算信譽路由的混合效應：

```
           ON份額(信譽)      均勻      OFF5品質
careful-1  16/60 (26.7%)    16.7%      25%     <= 最差的，信譽路由確實**超額**選它
careful-2   5/60 ( 8.3%)    16.7%      86%
hasty-1     5/60 ( 8.3%)    16.7%     100%
hasty-2     2/60 ( 3.3%)    16.7%      80%
plain-1    26/60 (43.3%)    16.7%     100%     <= 最好的，超額選得**更多**
plain-2     6/60 (10.0%)    16.7%      70%

信譽份額期望交付 75.14%   均勻份額期望交付 76.79%
** 混合效應 = -1.64pp **   (round61 用 OFF 1-shot 品質算的是 -1.33pp)
```

**這是本輪最反直覺的一件事**：`careful-1` 的品質估計從 75%（round61，n=4）掉到
25%（本輪，n=8 且題內配對驗過），**混合效應幾乎沒動**（-1.33 → -1.64pp）。
機制：信譽路由超額選了最差的 `careful-1`（+10.0pp 份額），但**同時超額選了最好的
`plain-1`（+26.7pp 份額）**，兩邊大致抵銷。

敏感度（把 `careful-1` 品質往最壞推）：

```
OFF5 點估計 25%   => -1.64pp
Wilson 下界 ~7%   => -3.44pp
最惡假設 0%       => -4.14pp
```

⇒ **即使 `careful-1` 的真品質是 0，路由混合也解釋不完觀測到的 -7.15pp ON-vs-OFF 落差。**

## 決定

**不開 ON-random-routing 臂**（維持 round61 的結論，推翻它的理由）。

- round61 的理由「池子沒有品質離散度」**已被本輪推翻**：離散度是真的（-45pp，配對驗過）。
- 新理由是**量測值**：路由混合的可歸因效應 -1.64pp（最惡 -4.14pp）。round61 自己定過
  本實驗在 n=60 的解析度——7.15pp 都已經 McNemar p=0.289 跟雜訊分不開，
  **開一條同樣 n=60 的新臂不可能解析出 1.64pp**。新臂會花掉約一小時算力去量一個
  它量不到的東西。
- 而且（Q1）**現在也開不起來**：v3 仍在跑（OFF5 11/60），第二支 run 打同一個 8765 中轉
  會互相拖慢，**延遲是實驗條件**（SPEC_GAIN §7）⇒ 併跑會污染兩邊的延遲數字。

## 放棄了什麼

- 放棄「用一條新臂直接量隨機 vs 信譽」的乾淨對照 ⇒ 換成用 OFF5 品質 × ON 份額的
  **模型化推算**。代價：這是加法可分解模型，假設 persona 品質不隨臂變動；
  真臂會連 review/revise 的交互作用一起量到，推算不會。
- 放棄追究「ON 的 -7.15pp 到底從哪來」——本輪只證明了**不是路由**（≤4.14pp 上限）。
  剩下的候選是 review 誤殺與 revise 改壞，`analyze_revise_counterfactual.py` 已在追。

## 前瞻性推翻條件（取代 round61 那條，**這次把樣本數與序貫看資料一起寫進去**）

round61 那條的缺陷已經暴露：只寫了 p 與 pp 兩個門檻、沒寫最小樣本數，
於是 n=7 就字面達成、跟它自己的語境（~50/persona）打架。新條件：

**本決定（不開新臂）在下列條件**全部**成立時被推翻：**

1. OFF5 跑滿 60/60（或 `run_complete=true`），且 **min n/persona ≥ 30**；
2. 用 `analyze_off5_matched.py` 的**題內配對**（不是邊際）劣勢 ≥ 15pp；
3. 多重比較修正後 p < 0.05，**且對從 round63 起的 look 次數做 Bonferroni 後仍 < 0.05**；
4. **且**用當時品質重算的混合效應 **|效應| ≥ 3.0pp**（round61 定的解析度門檻，沿用）。

第 4 條是關鍵：前三條只說「persona 有好壞」，**第 4 條才說「這件事大到值得開一條臂」**。
本輪 1-3 都成立（除了樣本數）而第 4 條 **不成立**（-1.64pp）——這正是為什麼結論沒變。
