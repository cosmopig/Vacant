「**等預算下 ON 的實務劣化（>5pp）被排除**，且這個下界是保守的」。

**但沒有檢查過「整筆不見」那一類**——那是不同的一類，而且大得多。

## 一、本輪要答的問題

**round660 那句頭條（劣化 >5pp 被排除），對「把 void 全部當缺測丟掉」這個處理方式穩不穩健？**

丟掉是 SPEC 鐵律 2 的正確主格（void 不算成功也不算失敗）。本輪**不改主格估計量**。
本輪加的是一個**界**，不是一個新估計：對每一個被丟掉的配對，另一臂的結果其實**是知道的**，
所以可以問「若把不知道的那一臂填成對 ON 最壞／最好，Δ 會跑到哪裡」。

## 二、方法（新增估計量零、新增可調參數零）

沿用 round656 已雙向驗證的 `paired_ci.diff_ci(b, c, n)`，只換餵進去的 (b, c, n)。
把任務依「兩臂 row 在不在」分四類：

- **both**：照舊（主格）。
- **ON 缺、OFF5 在**：ON 是 void。最壞情形填 `ON=False`、最好情形填 `ON=True`。
- **OFF5 缺、ON 在**：OFF5 是 void。最壞（對 ON）填 `OFF5=True`、最好填 `OFF5=False`。
- **兩臂都缺**：**一律排除**。兩邊都沒有資料，填任何值都是捏造，不是界。

三個數字並列報：`drop`（主格＝round660）、`worst_for_ON`、`best_for_ON`。
這是 Manski 型的無假設界：真值必落在 `[worst, best]` 之內（只要「兩臂都缺」那類真的無資訊）。

## 三、事前寫死的判定規則（**量完不准改**）

以 `PRACTICAL_PP = 5.0`（沿用既有慣例，非本輪新旋鈕）判：

1. **穩健**：`worst_for_ON` 的 95% 下界 `L_worst ≥ −5.0pp`
   ⇒ round660 的頭條句原文照留，並加註「對 void 處理穩健」。
2. **不穩健**：`L_worst < −5.0pp`
   ⇒ round660 的頭條句**必須降級**為「在『void 全部視為缺測』之下成立，
   對 void 處理不穩健」，且**不得**再單獨引用 −3.92pp 當結論。
   降級是本輪的產出，**不是失敗**。

⚠ 兩個方向都先寫死了，量出來哪一邊都照登。**不准量完再挑門檻、不准改分組、不准改納入規則。**

## 五、量具雙向驗證（**不過就不准報數字**）

新工具 `ops/gain/replay/void_bounds.py --selftest`，乾淨必須 PASS，
下列突變體**每一個都必須 FAIL**，否則判本輪工具沒有牙齒：

- **V1**：`worst_for_ON` 把 ON 缺的填成 `True`（方向填反）⇒ 界不再包住主格 ⇒ 必須被 P-B 抓到。
- **V2**：「兩臂都缺」也拿去填（憑空造配對）⇒ 必須被 P-C 抓到。
- **V3**：`worst/best` 的 n 忘記加上被救回的配對（只加 b/c 不加 n）⇒ 必須被 P-D 抓到。

自檢命題：
- **P-A**：void 皆為 0 時，三個數字（drop/worst/best）必須**逐位元相同**（退化相容）。
- **P-B**：恆有 `delta_worst ≤ delta_drop ≤ delta_best`（界必須包住主格）。
- **P-C**：納入的配對數 = both + 單邊缺；**兩臂都缺的數量不得進 n**。
- **P-D**：`n_worst == n_best == both + 單邊缺`（兩個界用同一個分母）。
