# Task

Turn a whole number of seconds into a clock-style label made of
hours, minutes and seconds with colons between them.

The hours are always shown and take as many digits as they need. The minutes
and the seconds always take exactly two digits each.

## Interface

    hms(total_seconds) -> str

Write the code in a file called `solution.py` in this directory.
Nothing else is needed and nothing else is read.
