## 二、P-R662-2 被推翻，**但判準裡寫的那個替代解釋也同時被推翻**

CRITERION §三對 P-R662-2 預先寫了：「若 S6 仍以 `HTTP_400` 為主 ⇒ R356 修復未生效」。
**這個替代解釋被 Q2 直接否證**——S6 的 400 失敗呼叫 `attempt` 分佈是

```
S6（修後 58 秒起跑）  {1:226, 2:167, 3:82, 4:42}   最大 attempt=4  ← 重試真的發生了
S5（修前）            {1:125, 2:  7, 4: 1}         最大 attempt=4  ← 幾乎都停在第 1 次
```

⇒ **R356 的 400-改為重試在機制上確實生效了**（S6 有 167/82/42 次真實重試，
S5 幾乎全部 attempt=1 就 break，符合當時的 non-retryable 設定）。

**所以真相是第三種狀態，兩個事前選項都不是**：
**修復生效了，但沒有降低 void——重試 4 次之後那些 400 仍然全數失敗。**
R356 當初的推翻依據是「同一 task 在另一臂成功過」（等價形式），
那證明的是**題目內容沒問題**，**不等於重試救得回那一格**。本輪把這兩件事分開了。

## 四、事後追查（**明確標記為事後，不列入預測計分**）

- **H1 context overflow 被否證**：400 失敗呼叫的 prompt 長度與成功呼叫幾乎相同
  （S6：gen 中位數 350 vs 359、review 1253 vs 1262），且**最長的 prompt 全部成功**
  （gen max 成功 1119 > 失敗 1093）。若是長度溢位，400 應該落在長尾——沒有。
- **H2 400 是隨時間變動的，不是內容決定的**：
  S5 前 126 分鐘 **0/123 = 0.0%**，之後才起跳並維持 8–17%；
  S6 由 14% 一路升到第 9 段 **51.4%** 再回落。
  題序是固定 seed ⇒ 內容決定的失敗會在時間上均勻，實測不均勻。
- **H3 storm 會同時打中所有臂**：S5 有 **47/90** 個被 void 的任務是兩臂同時 void
  （Jaccard 0.52），與 round661 獨立算出的 47 完全一致。
  ⇒ P-R662-5「可補量」偏低（42.8%）**主因是另一臂當時也被 void**，
  **不是**模型對該題內容穩定拒答。**這兩件事必須分開講。**
- **H4（本輪最有行動價值）ON 臂在結構上就比較容易 void，原因是重試預算**：
  `role="review"` 在 `gain_run.py` **只出現在 `arm_on` 內**（全檔唯一一處，line 692），
  而它的 `retries_max=2`，`gen`／`revise` 都是 4（實測 attempt 分佈：
  S6 review 只到 2、gen 到 4；S1 review 只到 2、gen 到 4）。
  同一個 run 內：**S6 OFF void 2.8%、OFF5 16.8%、ON 36.9%**，
  而 **OFF5 的呼叫數還比 ON 多**（804 vs 660）卻 void 得少一半
  ⇒ **純曝險（呼叫數）解釋不了，ON 特有的是那個 2 次上限的 review 呼叫。**
  跨池成立：Group A 的 16 筆 void **全部**落在 ON 臂。
- **H5 400 的伺服器說明被丟掉了**：`brain_cline.py:182`
  `last_err = f"{type(e).__name__}: {e}"`；對 `urllib` 的 `HTTPError` 而言
  `str(e)` 只有 `HTTP Error 400: Bad Request`，**回應本體（`e.read()`）沒有落盤**。
  S5 的 133 筆與 S6 的 517 筆 400 訊息**逐字完全相同**，沒有任何可辨識資訊。
  ⇒ **目前這批 log 無法再往下追根因**；這是一行可修的儀器缺口，
  且它正是 R440D「infra 未修前不再起 qwen run」卡住的那個 infra。

## 五、對頭條的影響（**只講證據支持的，不外推**）

round661 的 Manski 界把 `worst_for_ON` 定義為「每個 ON void 都失敗 **且** 每個 OFF5 void
都成功」。H4 說明 **ON void 較多是重試預算的組態造成的**，H2/H3 說明 **void 由
端點的時變故障造成、與題目內容無關**。

⇒ 這**強化**了 round661 已寫的那句「界不是情境」：最壞界所描述的世界
（ON 系統性地在它 void 的那些題上比較差）**缺乏機制上的支持**。

⚠ **但這不足以把界收窄。** 機制證據說「最壞情境不像真的」，
**不等於**在數學上排除它。**頭條照 round661 原樣寫，本輪不改頭條數字。**
