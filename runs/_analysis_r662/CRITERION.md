## 一、判別量（機制導出，新增可調參數 0）

對 6 層 × 每層 `notes.jsonl` 裡**每一筆**帶 `infra_void` 的紀錄（不抽樣）分類：

1. 字串以 `sandbox verifier unavailable:` 開頭 → `SANDBOX`
2. 否則匹配 `^(?P<agent>.+?) 重試 (?P<n>\d+) 次仍失敗：(?P<last>.*)$` → `ENDPOINT`，
   再依 `last_err` 子分類（**依序，先中先算**）：
   - `HTTP Error (\d{3})` → `HTTP_<code>`
   - 含 `timed out` / `timeout` / `TimeoutError` → `TIMEOUT`
   - 含 `Connection` / `Remote end closed` / `URLError` → `CONN`
   - 其餘 → `OTHER:<異常類名或前 60 字>`
3. **兩條都不匹配 → `UNPARSED`**

⚠ `UNPARSED > 0` ⇒ 判定 **BROKEN**，不准安靜跳過、不准當作 0
（記憶規則：「安靜量不到」要 BROKEN 不是 PASS）。

⚠ `ENDPOINT` 訊息裡的「重試 N 次」印的是 `effective_retries` **設定值**，
**不是實際嘗試次數**（`brain_cline.py` 註解自述，R356 實測）⇒ **不得**用它算重試。
實際嘗試次數只能從 `calls.jsonl` 的 `attempt` 取。
