# Task

`dedupe(xs)` takes a list of strings and gives back a list with the
repeats taken out, in the order the survivors were first met.

The strings are tags that people typed themselves, so the same tag arrives
typed several different ways and the team wants one row per tag, spelled the
way it was first written down.

## Details

- the comparison ignores case, and the spelling kept is the first one seen.

Write the code in a file called `solution.py` in this directory.
Nothing else is needed and nothing else is read.
