# Task

`running_total(xs)` reports the total accumulated as a list of
numbers is walked from the start.

It feeds a chart where each point sits above the reading it belongs to, so a
point and a reading have to line up.

## Details

- the answer is the same length as the input, and each entry includes the reading at that position.

Write the code in a file called `solution.py` in this directory.
Nothing else is needed and nothing else is read.
