# round660 結果（判準見同目錄 `CRITERION.md`，先 commit `eed6126` 才開始量）

## 摘要

1. **r658 的合併工具有一個安靜失效的擋門，本輪修掉並補上有牙齒的測試。**
2. **r658 的排除規則其實有兩條理由，它只寫了一條**（尺 + 池）；池不同**離線重放修不掉**。
3. 舊尺資料只在**下界方向**有效 ⇒ 多拿到 **593 配對題**，但**只能加固「非劣性」那一側**。
4. **P-R660-4 被自己的資料推翻**：Group B 的保守下界 `L=−5.12pp`，**差 0.12pp 沒過 −5pp**。

## 一、缺陷（P-R660-1 成立）——用**修改前**的工具實測

六層直接餵進 round658 的 `pooled_paired_ci.py`：

```
p_het_fisher             = None
het_verdict              = HOMOGENEOUS_NOT_REJECTED
pooled_usable_as_headline= True      ← 擋門根本沒跑，卻放行當頭條
opposite_direction_strata= True      ← 而且各層方向真的不一致
broken_reasons           = []
rc = 0
```

肇因是 `main()` 的 `p_het = fisher_exact_2x2(...) if len(strata) == 2 else None`，
加上 `het = "HETEROGENEOUS" if (p_het is not None and ...) else "HOMOGENEOUS_NOT_REJECTED"`
——**`None` 落進了「未拒絕同質」那一支**。層數 ≠2 時擋門形同不存在。

**修法（新增估計量零、新增可調參數零）**：Fisher 2×2 改跑在**兩個 group 的加總 (B,C)**；
`p_het is None` 另立 `GATE_NOT_RUN`（不再併入「未拒絕」）；group 數 ≠2 ⇒ 進 `broken_reasons`、rc≠0。
兩層不帶 group 時退化成 round658 的逐層 2×2（**P7b 驗到逐位元相同**）。

### 量具雙向驗證（`SELFTEST.txt`）

```
乾淨 → SELFTEST PASS  rc=0   （P1 加法恆等式／P2 照 n 加權／P3 Fisher 對稱／P4 有牙齒／P5 分組擋門／P7 缺 group 要 BROKEN／P7b 向後相容）
M3（合併寫成未加權平均）      → FAIL: P2   rc=1
M4（p_het 恆回 1.0）          → FAIL: P4（連帶 P5） rc=1
M5（擋門退回 len(strata)==2） → FAIL: P5, P7        rc=1   ← 就是本輪修掉的那個安靜失效
```

M5 讓 P5 破 ⇒ **P6 滿足**，新測試對「安靜失效」這一型有牙齒。

**向後相容實測**：Group A 兩層跑出 `p_het = 0.5639234907191044`，與 round658 逐位元相同；
Δ=+1.20pp、`[−4.46,+6.70]`（round658 是 `[−4.48,+6.73]`，差異來源是 E3 這輪多了 1 個配對題，N 250→251）。

## 五、頭條可以怎麼寫、不可以怎麼寫

**可以**（下界方向，A1 之下有效）：

> 把磁碟上全部 6 個含 ON/OFF5 的 run 合併（N=**844** 配對題，是 round658 的 3.4 倍），
> ON 相對 OFF5 的差值下界是 **−3.92pp** ⇒ **等預算下 ON 的實務劣化（>5pp）被排除**，
> 且這個下界是**保守的**（其中 593 題用的舊尺系統性低估 ON）。

**不可以**：全體合併與 Group B 表面上都判 `RULED_OUT`（U=+1.15 / +0.30 ≤ +5），
但判準 §三／§五寫死：**舊尺低估 ON ⇒ 上界無效** ⇒ **不得**用這兩個數字說「ON 打不贏 OFF5」。
要講「打不贏」只能引用 **Group A**（`[−4.46, +6.70]`，仍是 `NON_INFERIOR_BUT_UNRESOLVED`）。

**還有一個解讀上的限制**：全體合併的 Δ 是**跨池的加權混合量**，不是任何單一 worker 池的效應。
