## 三、四個發現

### 1. 觀測台講了 28 次「信任」，「可究責」零次

紅線 B 的 29 條裡 28 條在觀測台（`app.html` 9／`app.js` 12／`dashboard.py` 7）。
**而它的 B 分母是 0。** 這兩個數字擺在一起才有意義：不是偶爾用錯一個詞，
是整個口徑還停在舊的那一套，替代詞一次都沒進去過。
單看 `--diction` 只知道「28 條」；要有分母欄才知道那 28 條沒有任何對照組。

### 2. 第 104 輪那個「觀測台 C 分母 8」是裸關鍵字計數，虛高

第 104 輪的事後診斷數出「`app.html` 提高成本 1 · 留下紀錄 1 · 改不掉 1；
`app.js` 提高成本 2 · 留下紀錄 3」＝ 8。本輪機器給 **1**。查下去：那 8 個裡面

- `app.js:203` 「尚無成本資料」— 面板欄位空狀態
- `app.js:213` 「單位成本品質的可觀測代理量」— 指標定義
- `app.js:102/158` 「尚無稽核紀錄」「尚無交付紀錄」— 表格空狀態
- `app.html:69/99` 「成本」「交付紀錄」— 欄位標題

**一條都不是在講「提高作惡的成本」或「留下改不掉的紀錄」。** 裸關鍵字會把
UI 標籤算成「有在講」，分母虛高，於是 `0` 被讀成「守線」而不是「沒講」。

唯一真的那條是 `app.html:37`「ledger 滾動雜湊：任一行被**竄改**／重排／刪除
都會改變它」——而我的 `R5` 原本只收「不可竄改｜竄改不了」，**把它漏掉了**。
是拿機器的 0 去對第 104 輪的 8 才照出來的。已修（收裸 `竄改`），觀測台 C 分母 0→1。

**分母本身也是量尺，一樣要先驗兩個方向。** 我第一版給分組函式做了探針
（G1 四格），卻讓分母詞族沒探針就上線。補了 `G2a/G2b` 九格，
「不准抽到」那半直接取自上面那些欄位標籤。

### 3. 我自己犯了總表要防的那個病，只是往上爬了一層

第一版的讀法欄把 A 的「命中 0 ＋ 分母 >0」寫成**守線**。錯的：
A 的分母是 SOLO **單邊句**（只講「抓到」或只講「後果」，沒把兩頭連起來），
分母 >0 只代表**講了一半**，那既不是踩線也不是守線。
為了防「沒講被讀成乾淨」而加的分母，自己又把「講了一半」讀成了乾淨。
A 欄現在是三態（命中／單邊／沒講），B／C 維持二態——B／C 的分母是
「該說的替代詞」，>0 ＋ 命中 0 才真的是守線。**A 與 B／C 不能共用同一句讀法。**

### 4. 三條紅線不是同一個東西的三種說法

`dashboard.py`：B 欄 7 條（全站第二髒）、C 欄 0 條。
`vacant_hm/world/js/main.js`：C 欄 3 條、B 欄 0 條。
髒檔沒有在三欄一起亮 ⇒ 三條紅線互相獨立，各自都得掃。
（若它們高度相關，總表就會證明其中兩條是多餘的。它沒有。）
