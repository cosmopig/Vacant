This kit contains twelve independent Python task workspaces, their exact user prompts in `prompts/`, and original visible-only Vacant acceptance suites in `gates/`; there are no hidden tests or reference solutions here. Create `.venv` at the kit root and install Vacant plus pytest there (`pip install git+https://github.com/cosmopig/Vacant pytest`): the wrappers explicitly use that interpreter because main's vrun verifier uses system Python with a cleaned PATH. Work inside the named task directory and use the visible gate only for the manual-gate arm; keep each submission's receipts outside the task workspace in `receipts/`.
